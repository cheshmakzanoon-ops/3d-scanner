# Historical campaign helper source

Exact existing external helper source is preserved at the user-requested stop point. These files contain fixed historical serials, source commits, artifact hashes and output paths. They are an archive, not a new execution entry point. Do not run them against a current candidate.

The production-facing role commands remain documented in the parent directory. Existing receipts retain actual completed outcomes; source archival adds no test, device, physical, upgrade or final-candidate PASS. No APKs, installed APK pulls, userdata, SDK binaries, credentials or caches are included.

`inventory.json` records each original path and exact byte hash. The historical coordinator receipt generator, where present, has superseded counts and paths and must not be used to replace current receipts.
