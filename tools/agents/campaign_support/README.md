# Preserved campaign support source

Archived existing source at the user-requested development stop. These are
historical environment-specific coordination, setup and independent-review
helpers, with original absolute paths and assumptions preserved. They are not
new supported product entrypoints. Do not run historical receipt generators
against current evidence or infer test success from a preserved script.

`source-index.json` records the original paths and hashes. `scratch-patches/`
preserves existing temporary wiring variants; the owner branches hold the actual
deliveries. Generated caches, binaries, credentials and negative-test worktrees
are excluded. No final candidate validation was started by this archival commit.
