# Historical support source archive

Exact existing campaign helper bytes preserved at the user-requested STOP.
These are one-time source/evidence preparation or review scripts with historical
absolute paths and assumptions. They are not maintained public entrypoints,
current policy approval, or a new validation run. Do not run them against a
current checkout: some write historical evidence or draft/source files.
No script was executed, repaired, or qualified as part of this archive.
`inventory.json` records original paths, byte counts and SHA256 identities.
