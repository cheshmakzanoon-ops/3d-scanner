# Bounded native input regression

From this checkout with CMake, Ninja and host Clang/compiler-rt available:

```sh
python tools/qa/fuzz/run.py --compiler /usr/bin/clang++-18 --runs 1000 --seconds 30 --output /tmp/rf-fuzz
```

The standalone CMake project compiles the actual native library with address/undefined-behavior sanitizers and libFuzzer coverage. It does not modify central CMake registration. Three targets exercise bounded numeric buffers, the real checkpoint binary reader, and point/surface/texture serializers. Counts always describe allocated buffers; a raw pointer ABI cannot infer a shorter allocation. JNI length regressions are separately compiled into the test APK. No scanner photos, device files, credentials or network inputs enter the corpus.

All initial bytes are deterministic synthetic CC0-1.0 test fixtures generated by run.py, including a valid CRC-bound 32×32 checkpoint and explicit corrupted variants. Each target uses at most 16 KiB input, 256 MiB single-allocation and 1 GiB process RSS limits, a three-second per-case timeout, fixed seed and an overall wall-clock deadline. ASan leak checks and UBSan halt-on-error stay enabled. Logs, binary/corpus hashes and minimized libFuzzer failure artifacts remain outside Git in the selected output folder. A missing compiler is NOT_RUN with nonzero exit; build/runtime/assertion/timeout errors remain FAIL. Successful host checks never satisfy Android JNI or physical gates.

To replay a discovered artifact, invoke its recorded target with the artifact path and sanitizer environment from evidence.json. Preserve its hash, reduce with libFuzzer's documented `-minimize_crash=1` mode within the same budgets, and send the exact source/command/minimal input to the semantic owner. Do not change an algorithm/parser merely to silence the harness. The assigned shared-build owner is 004; the exact optional registration request is committed under docs/agents/requests/082-to-004.md.

Android bounded bridge checks run with explicit serial through Agent092's runner or `adb -s SERIAL shell am instrument -w -r -e class com.realityforge.scanner.qa.FuzzBridgeContractTest com.realityforge.scanner.test/androidx.test.runner.AndroidJUnitRunner`. No attached Android device is present in this environment, so compiled test sources are not claimed as executed instrumentation.
