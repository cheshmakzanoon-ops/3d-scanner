# Dependency and attribution checklist

First-party project source in this repository has not been assigned an open-source license.
The project owner should select its distribution license.
No third-party source code is vendored into the native numeric core. The synthetic regression
fixture is generated by tools/make_fixture.py; it is not a downloaded real-object scan.

The intended Android build resolves these direct dependency families from their official
repositories: Android Gradle Plugin, AndroidX/Jetpack, Kotlin, kotlinx.coroutines, KSP,
OpenCV, JUnit and Android test support. Exact versions are in build.gradle.kts and
app/build.gradle.kts. The official Gradle 8.13 Wrapper is committed with its pinned checksum,
distribution checksum and embedded Apache 2.0 license (`gradle/wrapper/LICENSE`). Explicit
repair helpers verify the same checksum; normal builds do not bootstrap a missing wrapper.

The audit adds `org.json:json:20250517` only to the local JVM test classpath, so tests execute
the real codec instead of Android's throwing mock methods. Its pinned
[upstream POM](https://github.com/stleary/JSON-java/blob/20250517/pom.xml) declares Public
Domain. It is not an Android runtime dependency. Room 2.7.1, CameraX 1.4.2, coroutines 1.10.2
and OpenCV 4.12.0 retain the repository's existing pinned runtime versions; the audit does
not add Filament, Vulkan, model downloads or network SDKs.

Before distributing an APK: generate a complete dependency/native-library inventory, inspect
each resolved license/notice, include the applicable texts, and inspect the final package.
This source-level checklist is not a completed legal review or final redistribution notice.
No OpenMVS or other AGPL reconstruction code has been included. Ceres, Eigen, Filament,
xatlas, meshoptimizer and Vulkan MVS remain planned integrations, not current packaged code.

use OpenCV 4.12.0.88 while Android pins 4.12.0. Host test success still does not certify the
packaged Android binary; APK inspection and Android instrumentation remain separate gates.
