Representation: conforming arrangement of projected original observed triangle
edges in one single-valued chart; constrained triangulate only source-covered
cells; each output vertex has one shared ray lift; retain an immutable complete
source observation ledger and explicit per-face source triangle contributors.

The first safe lift policy admits only agreement within arithmetic roundoff,
not a new physical noise/merge tolerance. Distinct depths are ambiguous rather
than silently merged. This can represent curved charts where source interpolation
agrees, but translated curved discretizations can be refused. Such refusal is
an honest limit, not a reason to tune a threshold. No arbitrary global chart
selection, automatic cross-chart seams, or object-wide planar assumption.

Controls frozen before running candidate:
- identical and translated plane grids; rotated grids; input-view permutations;
- partial overlap and complementary support; a hole absent from every view;
- curved identical grids and curved translated grids;
- a measured discontinuity; thin separated same-facing sheets;
- finite/malformed source rejection; candidate/fragment/output caps;
- cancellation and atomic no-result publication on failure.

Success: translated planar overlap has zero proper intersections/nonmanifold
edges; original triangle support union and holes preserved; all original source
IDs retained even without an output vertex; no falsely successful layer merge;
permutation-invariant output geometry. Face count is not a quality metric.

fold, or cancellation rejects the entire candidate atomically. Do not omit hard
faces or fall back to a single view. A passing chart kernel is not a global
surface replacement. GEOS calls are QA subprocess-bounded; no claim of native
cooperative cancellation within GEOS or Android deployment.
