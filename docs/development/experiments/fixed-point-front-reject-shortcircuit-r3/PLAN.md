## Deterministic proposals and front

1. Canonical point order is exact represented XYZ lexicographic order, then immutable accumulator ID. A spatial grid only accelerates enumeration; exact distance decides all neighbors within 2*rho, including equality. Retain coincident point identities; degenerate triples refuse rather than merge/split points.
2. Enumerate each unordered triple with all three edge lengths <=2*rho exactly once, lexicographically by canonical point keys. Predeclare ordering before outcomes. Use a packed triple table, not an unbounded Python object cache. Every proposed face uses existing camera-member ray hemispheres to choose orientation; conflicts/grazing refuse, unknown point normals are never filled in.
3. Reviewed exact sphere/radical predicates construct the rho-ball on the camera-facing side of the oriented triangle. Circumradius>rho or collinearity refuses. Exact co-spherical points are allowed on the ball boundary, never treated as interior; deterministic proposal/front ordering resolves competition. Test every point in the complete 2*rho neighbor list of a triangle vertex for strict interior occupancy. This is complete because that vertex lies on the sphere; any interior point is within 2*rho. No arbitrary nearest-k truncation.
4. Each candidate must pass the unchanged R3 whole-union closed-boundary support, actual strict reciprocity, all-contributing-source normal constraints, and observed visibility predicates across all eight cameras. Preserve the existing .055 represented tolerance; no new uncertainty/confidence claim. Positive-area and boundary-only support both remain checked. Logical geometric refusal is distinct from work/numeric budget exhaustion; the latter aborts the whole case.
5. Seed the earliest admissible proposal; process oriented boundary edges in canonical order, trying compatible untried incident proposals in canonical triple order. New faces must traverse any shared edge oppositely, leave edge incidence <=2, and leave every affected vertex link a connected path or cycle with degree<=2. A point-star that would be temporarily disconnected is refused rather than repaired later. Exhaust an open edge without filling it if no candidate qualifies. When no frontier grows, attempt the next admissible untried seed; never seed a disconnected second star at an already referenced vertex. Scan until all proposals are accepted/refused/accounted, not until a pleasing component exists.
6. This is a conservative order-dependent experiment, not guaranteed maximal coverage or triangulation uniqueness. No final component deletion, index splitting, face cleanup, hole caps or other topology repair. Native quality diagnostics inspect exactly the emitted mesh.
