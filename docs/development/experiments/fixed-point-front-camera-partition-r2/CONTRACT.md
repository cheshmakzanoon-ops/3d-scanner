# Frozen fixed-point global-front experiment contract

Source/config must be frozen before controls, independently reviewed before the whole dataset. Oracle-camera component only; all eight fixed images, camera rows and original search bounds are unchanged prerequisite inputs. Original geometry/masks are read only by the sealed evaluator. No production integration or parameter sweep.

The original design is retained in PLAN.md. This implementation clarifies the following executable details before any measurement:

- All R3 exact geometry/support/closed-boundary/orientation/ledger modules are byte-identical to the reviewed checkpoint, as recorded in reused-source-provenance.json. Existing stronger native bit and witness auditors run before conversion. The bridge is a schema conversion, not new measurement generation; all rich records remain input-hash-bound. Zero legacy witness extra fields mean unavailable, never observed costs. The current frozen input pins prove native directed/strict identities; the R3 graph still explicitly requires both directed edges.
- The source-cell run is reproducible via its separate committed package. Input-pins.json binds all consumed observation/depth/cell/support outputs and original baseline evaluation. Matched original native source files and headers are pinned; the actual shared library must match that replay's recorded build identity and loader resolution. No binary bundle or external download is needed.
- Derive rho exactly once from the median (mean middle pair if even) of binary64 Euclidean lengths of unique camera-local axial stride-2 edges occurring in admitted derived source triangles. Record every edge and h.hex before any candidate. Treat that represented h as exact rational for predicates. This is observed-sampling scale, not ground truth. No radius sweep or relocation.
- Canonical proposal order is represented XYZ followed by immutable original point ID, including coincident positions. Grid cells of width 2*rho accelerate complete radius-neighbor enumeration; all 27 adjacent buckets are visited, and exact squared distance decides inclusion. Complete neighbor-pair visits, all proposal-pair combinations (including rejected third edges), unique triples and front/link work each have explicit 2,000,000 caps. Oversized neighborhoods abort, never nearest-k truncate. The packed triple table preserves lexicographic canonical ordering.
- Use the reviewed exact sphere on the candidate's camera-facing oriented normal side. Co-spherical points are boundary, not interior. All original points, including unknown-normal and currently unreferenced points, obstruct an empty ball. The complete <=2*rho neighborhood of one on-sphere vertex contains every possible interior point, so no irrational sphere-center bounding approximation is needed.
- Every candidate passes the unchanged R3 complete union/closed-boundary, strict positive-corner reciprocal, visibility and source-triangle orientation predicates. No nearest-three-point substitute, camera dropping, new NCC query, invented confidence or normal is allowed. A declared geometric refusal is recorded; any work/bit/fragment/bounds failure aborts the whole arm rather than being relabeled a rejected face.
- Front boundary queue is ordered by oriented endpoint canonical ranks. Candidate lists use canonical triple order. The first admitted seed grows until no frontier face admits, then remaining seeds are visited in the same order. Every proposal is eventually classified. Edge incidence must stay <=2 with opposite shared-edge winding; each affected vertex link must be a connected path/cycle with degree<=2. A rejected temporary disconnected star is not revisited/tuned. This conservative order-dependent choice may lose coverage; that is an empirical NO-GO, not a repair opportunity. No final topology cleanup, split, smoothing, cap or component deletion.
- All 4,855 original point records and 9,172 observations remain in the immutable bridge. Referenced geometry export uses only an injective storage compaction, with export-point-map.json pointing back to original IDs; no coordinate/attribute change or index splitting occurs. Unreferenced points/observations remain explicit. Global faces use external sourceCamera sentinel 255 (not a native source camera), and full original source-attempt provenance separately. Native diagnostic faceEvidence labels these as generated, not original measurements. Pre-face vertex normals remain zero output attributes, not inferred measured normals.
- The immutable eight-camera validation partition retains every original attempt ID. Construction charges 15,734 visits; all 192 fixed queries charge 377,616 relevant checks including query charges, replacing 3,019,392 brute visits. The separate QA process proves ordered equality against the original brute enumeration and existing index. Geometry has one unchanged shared 5 million clip/index/support cap including partition construction; there is no reset. Exact ball checks remain 10 million, fragments 4096 and rational bits 4096. Whole-case budget refusal remains NO-GO.
- Whole geometry and each controls/diagnostic/evaluation stage use actual 1 GiB address-space and 600-second CPU/wall caps. These are process limits, not claims about packed data RSS. Output <=256 MiB; geometry/provenance <=64 MiB, evaluator/log files <=16 MiB. On any first failure, preserve refused evidence, publish no successful geometry receipt, and stop before changed parameters/retry.

## Controls and gate

Run all reviewed primitive, closed-overlay and R3 schema controls unchanged, plus the actual new front on calibrated analytic plane/curve/hole/disconnected/fold and four-view layers. Analytic layer groups have two actual constructed exact correspondence view identities per layer; these are NOT native consistency execution or image reconstruction. Above-band layers must both survive without cross-layer faces. The below-resolution case is explicitly unqualified. Ordering controls compare cyclic-oriented faces, include a negative winding reversal, and exercise distinct immutable IDs at coincident points in a pure point-neighborhood/proposal unit control. Exact interior-hole, boundary-only support, free-space and occlusion tests remain part of reviewed R2 controls. Budget/cancellation must abort whole work.

Before the whole dataset run, independent review must inspect the full frozen implementation and completed control results. No whole run is authorized solely by a parser/control pass.

Strict final gates are fixed in gates.py: all eight per-view and aggregate projected coverage must not decrease; every existing reference/candidate distance CDF and per-view accurate-coverage CDF threshold must not decrease; every frozen p50/p95/max geometry or per-view camera-depth error must not increase. Reference observability/gauge must remain identical. Require no degenerate/duplicate/winding-conflict/nonmanifold-edge/nonmanifold-vertex faces and zero intersections AND zero unresolved ambiguous pairs, with native intersection sweep COMPLETE at unchanged 2,000,000 candidate / 1e-10 relative-tolerance settings. No predicate/tolerance change to certify an uncertain result. Empty or incomplete geometry, any coverage/accuracy/layer regression, or a budget refusal is NO-GO. All metrics remain visible, even when topology improves. Passing these empirical gates would still not be production approval or actual image-derived registration.

The controls also externally interrupt a synthetic long-lived actual front worker through the unchanged bounded process-group helper with SIGINT and SIGTERM. The worker ignores TERM; the owner must force bounded cleanup, retain an explicit refusal, and leave no successful geometry receipt. An outer native/evaluator failure likewise makes all candidate/geometry-receipt files refused scratch only: only the final outer receipt plus gates constitutes a completed comparison, never an inner geometry receipt alone.
