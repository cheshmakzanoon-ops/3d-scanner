# Direct-depth native pre-face observer — first checkpoint

Scope: two small synthetic **direct-depth** fixtures, never photographic reconstruction. Source pinned to `173dc71d7d99e97a8e2d4257b52cf7033e37a74f`. The exact committed `plane(false)` generator is extracted with a checked textual identity. The second case removes a declared central block from both maps and constructor-supplied samples. All configuration and source hashes are frozen before measurements; baseline-generated input field-bit hashes are recorded in `premeasurement.json` before fusion runs.

Three private read-only hooks log existing prepared normal/bound evidence, actual accepted source membership/weight, and all materialized accumulators before any faces. No query, normal estimation, weight, association or face decision is added to the observed library. A standalone harness reruns unchanged native normal helpers against the original maps and compares the resulting prepared evidence. Python independently audits ordered accumulator fields and float32-derived weights. Unknown normals and all original accepted observations remain retained.

Constructor-supplied `verifiedSamples` and `supportingViews` are NOT computed reciprocal witnesses. The complete reciprocal loop exists inline in `dense.cpp`, not as an API for external maps. No copied loop or new visibility query is executed. Reciprocal witness regeneration is NOT_VERIFIED; no full R3 support certificate, global front or image-derived quality result is claimed.

```sh
python -B run.py /path/to/repo/containing/pinned/commit /fresh/external/output /path/to/cmake
```

Prerequisites: Linux, Python 3.12+ (safe tar extraction), an explicitly supplied CMake executable plus system `/usr/bin/{git,c++,prlimit,ldd}`, existing C++20 toolchain and Zlib development files. No network or dependency installation. The runner creates two clean matched source builds with only private `surface.cpp` logging additions and a private header; native code/headers are never mixed across revisions. Loader resolution, tools, source archive, patched source, configs, libraries and outputs are hash-bound. Build processes use two jobs with a 15-minute timeout; native runs enforce 1 GiB address-space and 60-second CPU/wall limits. Signal-masked spawn and bounded TERM/KILL process-group cleanup apply to every subprocess. No sanitizer bypass is used.

The frozen `config.json` limits the two 32×32, two-view cases to 162 samples/memberships/accumulators and 1,458 normal support IDs. Sidecar writes have a shared 8 MiB budget. Generated mesh cardinalities are bounded before export; total case output is checked against 16 MiB before success. Output files are diagnostic scratch artifacts until the final receipt; on any error they remain refused evidence, never a successful publication. No binary/build/mesh bundle belongs in Git.

Baseline/observer parity requires identical canonical field-bit inputs and complete final mesh/provenance/diagnostic fields, JSON, PLY and GLB bytes. Input fields are checked again after fusion. Normal evidence includes all original support IDs, validity/uncertainty fields and prepared normals/bounds; original maps must match source projections under unchanged native gates. Numeric computation is not called calibrated physical uncertainty. Execution and independent review are reported below.

The first launch refused before builds or fixture execution because `/usr/bin/cmake` was absent. The retained source revision and refused output remain external evidence; the portable runner now requires an explicit existing CMake executable and hashes it. No tool installation or measurement was performed by that refused launch.


The committed `plane(false)` cameras have identical extrinsics. These are coincident-camera native mechanics controls, **not independent physical viewpoints**. Input mutation checks cover every `DenseView`, map depth/confidence and `VerifiedDepthSample` field; unused `DenseResult` points/sourceViews/diagnostics remain empty/default in the generator and are not serialized. No complete arbitrary `DenseResult` object mutation claim is made.

The first measured plane run passed original input/output and prepared-evidence byte parity, but its Python accumulator auditor refused negative zero. Native first-member assignment preserves a negative-zero weighted-normal component, whereas starting at +0 and adding erased that sign. `preserved-first-audit-failure/` retains the executed auditor, manifest, refusal and input identity. The revised auditor reproduces native first-member assignment before subsequent ordered additions; bit comparisons are not relaxed. The central-hole fusion was not run in that failed execution.
