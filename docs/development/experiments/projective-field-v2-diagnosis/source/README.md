# Public source with environment inventory withheld

Algorithmic C++ observer, predicates, serializer and driver are byte-exact executed sources. Tests, audit and supervisor have explicitly labeled configurable path substitutions and are NOT exact executed files. Their original private raw-source hashes are in artifact-bindings.json. These public variants have not been compiled or executed.

config.json is redacted metadata, NOT executable configuration. Complete private pins, empty-dependency lists, host/toolchain paths, command arguments and reverse-config patches are deliberately unavailable here. Local reproduction would require separately authorized provision of immutable private inputs and an independently reviewed fresh local configuration; this archive does not claim self-contained portability.

DIAGNOSTIC_ORIGINAL_TESTS_HEADER, DIAGNOSTIC_DEPENDENCY_ROOT, DIAGNOSTIC_REPOSITORY_ROOT, approvedScratchParent and toolSearchPath are generic placeholders, not instructions to use broad host directories. Do not use the illustrative source without restoring reviewed bounds and dependency validation in an authorized local setup.
