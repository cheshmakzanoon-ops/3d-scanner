# Physical capture protocol v1

Gate owner086. Only explicit authorized objects, photographs and reference geometry may be used. Keep private source assets/archives and full reports outside Git; commit reviewed manifests/hashes only. This protocol qualifies input identity and capture behavior;083/084 evaluate geometry independently.

1. Use a disposable installation on an actual ARM64 phone, record device make/model/OS/build, ambient lighting/temperature, app APK SHA256 and acquisition authorization. Discover the installed candidate using `python tools/device/capture_validation/qualify.py discover --serial SERIAL --app-apk APP.apk --output PRIVATE/device.json`. An emulator or candidate mismatch fails.
2. Capture at least two distinct matte textured objects, each with 12–40 originals, multiple heights and a full orbit with substantial adjacent overlap and consistent diffuse lighting. Record selected logical/physical camera ID, fixed optical lens, 1x zoom, focus/exposure strategy and any CameraX limitation. Do not infer focus from EXIF alone. Avoid moving/specular/transparent subjects for eligible acceptance; adverse scenes are separately labeled rejection tests. Current baseline reconstructs at most12 sparse/eight depth views; a larger input archive does not establish larger active workload support.
3. Capture10–40 varied views of a9x6 inner-corner checkerboard using exactly that camera/lens/crop/orientation. Run app calibration and retain source images plus `checkerboard.json` schema1 `{cameraId,photos:[{localPath,sha256}]}`. Record accepted views and profile SHA256; exported `camera-calibration-v1.json` must match. Obtain independent measured reference mesh (units m/mm and method), never use reconstructed output as its own reference.
4. Exercise permission denial then grant, Back/background interruption before/after shutter callback, device rotation0/90/180/270, fixed lens selection, focus/exposure consistency, local import→reconstruction→viewer→reopen. For each scenario retain an actual log/screenshot/trace with `status`, `evidencePath`, `evidenceSha256`. Unavailable or failed scenarios cannot be PASS. Bind capture session/project/revision in evidence; route late-callback capture issues to014/001 and calibration issues to027.
5. Run the physical instrumentation contract against an operator-created test project: `adb -s SERIAL shell am instrument -w -r -e class com.realityforge.scanner.qa.PhysicalCaptureContractTest -e physicalProjectId UUID -e physicalCameraId ID com.realityforge.scanner.test/androidx.test.runner.AndroidJUnitRunner`. Retain `physicalCaptureReceipt` and its exact original hash list. This checks actual private originals/Camera2/Exif/JPEG bounds; it does not automate the operator CameraX scenarios. Export capture ZIP using the app without recompression.
6. Write a private session JSON: schema1, authorized true, source `physical-camera`, objectId, appSha256, deviceFingerprint, cameraId, zoomRatio1, heights array, lighting, savedOriginalSha256s from instrumentation, observations for permissionDenial/interruptedCapture/rotation/focusExposure/importReconstructReopen each with status/evidencePath/evidenceSha256, calibration `{cameraId,acceptedViews,profileSha256,checkerboardManifestPath,checkerboardManifestSha256}`, referenceGeometry `{localPath,sha256,independentMethod,units}`. Paths resolve relative to session JSON, checkerboard photo paths relative to checkerboard manifest. Run `python tools/device/capture_validation/qualify.py audit PRIVATE/session.json PRIVATE/capture.zip --device PRIVATE/device.json --output PRIVATE/capture-audit.json`. Tool verifies referenced evidence bytes, exported original hashes, real JPEG/EXIF, same-lens calibration metadata and crop, and independent reference file identity. Install pinned Pillow with this directory's requirements if needed.

Two authorized objects and all scenario evidence remain BLOCKED_EXTERNAL until actual acquisition. Hashes prove byte identity, not honest operator observations or numerical quality; review logs and use083/084 metrics before acceptance. No physical originals are committed by these commands.
