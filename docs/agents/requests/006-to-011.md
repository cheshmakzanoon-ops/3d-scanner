# Agent 006 → Agent 011: replace the default photo import provider without bypassing C6

- Requesting agent: 006
- Receiving agent: 011
- Contract: `docs/agents/contracts/006.md` (`c6-v2`)
- Target path/symbol: bounded document-provider ingestion and `PhotoImportService`

Supply the production `PhotoImportService` implementation behind `ProjectStorageServices`. The
repository already owns the outer `IMPORT_PHOTO` exclusive reservation and fixed revision check, so
the provider must not reacquire another project lease or mutate through an uncoordinated DAO. Keep
streaming bounds, SHA-256 duplicate detection, partial-file cleanup and final DB invalidation inside
the active operation.

Required races: import versus delete/reconstruct/export on one project, two-project independence,
provider cancellation/short read, and process interruption before and after final rename/DB commit.
