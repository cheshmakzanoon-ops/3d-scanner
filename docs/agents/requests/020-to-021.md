# Agent 020 handoff to Agent 021 — reclaimable storage values

Use measured `CacheInventory.bytesByCategory` for current derived usage. Use `CleanupPlan.reclaimableBytesByCategory` only as a dry-run estimate, and `CleanupExecutionResult.deletedBytesByCategory` as logical bytes actually removed in that invocation.

Neither planned nor deleted logical bytes guarantee filesystem free-space growth. Re-probe available storage and rebuild the inventory after cleanup. A reservation must not assume unknown files, originals, active references, or retained results are reclaimable.
