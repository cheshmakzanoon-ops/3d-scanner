# Handoff 029 → 007: authoritative durable job adapter

- **Requesting agent:** 029
- **Receiving agent:** 007
- **Source commit:** campaign base `ad3029193f304c70931b94ea7a0df90b69d84b07`; consume the head of `agents/029-processing-notifications`
- **Target path/symbol:** Agent 007 durable job record/repository and current-job lookup

## Problem / reproducer

The base database persists only project state. Notification actions cannot be safe across process recreation unless they are checked against an authoritative durable job/operation identity rather than project id or intent extras.

## Required adapter fields and lifetime

Expose a conversion to `PersistedProcessingJob` containing:

- opaque stable `projectId`;
- unique durable `jobId`;
- unique execution-attempt `operationId`;
- fixed non-negative `sourceRevision`;
- typed status and optional typed stage;
- stage-local completed/total only when both are known;
- persisted action availability;
- start/update epoch milliseconds.

The tuple must remain immutable for one attempt. A retry/replacement execution receives a new `operationId` (and normally a new durable job transition) so old PendingIntents cannot address it. Provide an atomic current lookup used at action-delivery time and a persistence transaction that validates all identity fields before pause/resume/cancel.

Do not put project names, detailed errors, image paths or thumbnails in this adapter. Agent 074/processing UI can load separate private detail after the app opens.

## Restore policy

Expose only notification-eligible snapshots to Agent 008. Define durable policy for whether an already dismissed terminal result is restored; do not blindly repost every historical completed job. Active queued/running/paused work must be recoverable after process recreation.

## Tests / verification

- stale job id, operation id, revision and project id each reject independently;
- process recreation preserves exact identity and current action availability;
- rapid replace/cancel/resume transactions cannot authorize an older intent;
- persisted progress never converts unknown totals to zero or fabricated percentages;
