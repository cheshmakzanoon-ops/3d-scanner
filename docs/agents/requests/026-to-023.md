# Agent 026 → Agent 023 integration request

- Requesting agent: 026
- Receiving agent: 023
- Source commit: `PENDING_AGENT_026_IMPLEMENTATION_COMMIT`
- Target path/symbol: verified artifact-set reader/publication lease owned by Agent 023

## Problem and reproducer

The transfer layer must not hash an arbitrary path and call it a current export. It requires a
committed artifact identity, expected length and SHA-256 that remain valid for the request.
Agent 026 regressions reject revision changes both after copying and during provider commit.

## Agreed interface

Expose a read-only conversion from a committed `VerifiedArtifactSet` member to
`VerifiedExportSource`, including project ID, exact result revision, canonical artifact key,
representation, expected bytes, SHA-256, display name and MIME type. Provide a resolver/lease
that returns the same identity only while the artifact remains exportable.

A previous completed result may be exported only when Agent 067 explicitly selected that result;
it must never be silently substituted for a stale current result.

## Minimal adapter pseudocode

```kotlin
fun VerifiedArtifact.toExportSource(): VerifiedExportSource
fun openExportLease(identity: ExportSourceIdentity): ExportSourceFileResolver
```
