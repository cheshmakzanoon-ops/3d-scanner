## Problem / reproducer

Artifact publication must not accept output from a stale worker or superseded attempt. Agent 023 compares an immutable operation ID and positive attempt before promotion and again in the metadata transaction, but those values must come from the durable job owner.

## Required interface fields / lifetime

Expose to the Agent 005 metadata adapter and Agent 002 producer:

- safe-token `operationId`, stable for the logical job;
- monotonically increasing positive `attempt` for each acquisition/retry;
- bound `projectId` and input `projectRevision`;
- durable state including at least RUNNING/PAUSED/CANCELLED/COMPLETED/FAILED;
- a publication-relevant CAS epoch changed when the active lease/attempt/state is replaced.

Only a RUNNING exact attempt can begin/commit. Pausing, cancelling, replacement acquisition, input mutation, or deletion must make the old attempt fail with a typed Agent 023 rejection. Marking the job completed and installing the result pointer should occur in Agent 005's same transaction where possible.
