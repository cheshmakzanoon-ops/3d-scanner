API and proposed adapter: FeatureCache(root,byteBudget).load(identity) returns Hit(CachedFeatures) or Miss(reason); store(record) returns false on IO/budget failure, never scan success. Identity includes original SHA256, decoder transform, extractor settings and OpenCV version. RF feature binary version2 has bounded exact payload, SHA256, image/count/128-column shape and validated coordinates/descriptors. Atomic unique temporary writes and hash-name-only byte eviction preserve unrelated files. CachedFeatures is a copied DTO with float[count*2], ARGB[count], float[count*128]; construct Mats only after validated Hit, release on conversion failure. Unsupported old binary is a recompute miss; there is no permissive legacy parser.

recomputes features and is not a failed or completed scan result. Input originals remain untouched.
