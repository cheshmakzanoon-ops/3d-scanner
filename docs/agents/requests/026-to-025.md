# Agent 026 → Agent 025 integration request

- Requesting agent: 026
- Receiving agent: 025
- Source commit: `PENDING_AGENT_026_IMPLEMENTATION_COMMIT`
- Target path/symbol: `CaptureArchiveWriter` output handoff owned by Agent 025

## Problem and reproducer

Capture archives currently write directly into a picker stream, which prevents a separate
byte/hash verification and typed partial-destination handling. The transfer layer must consume
archive bytes without duplicating ZIP encoding.

## Agreed interface

Agent 025 should complete and validate its archive into a staged, revision-bound artifact, then
publish `VerifiedExportSource` for that ZIP. Agent 026 transfers the staged bytes to the bound
SAF destination. Cancellation before archive publication belongs to Agent 025; cancellation
during destination transfer belongs to Agent 026. Preserve the exact archive SHA-256 in the
transfer receipt.

## Minimal adapter pseudocode

```kotlin
val archiveSource: VerifiedExportSource = archiveWriter.publishValidated(...)
transferService.transfer(archiveSource, boundDestination, cancellation, progress)
```
