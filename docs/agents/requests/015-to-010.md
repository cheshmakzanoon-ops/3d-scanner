# Agent 015 → Agent 010 diagnostics request

Agent 010 owns the shared typed failure/diagnostic schema.

Please map the stable optical-control codes listed in `docs/agents/contracts/015.md` into the
shared diagnostic model. The UI owner will localize them. Preserve the distinction between:

- unsupported/unavailable capability,
- platform acknowledgement without capture-result confirmation,
- command failure/timeout,
- stale session completion dropped after teardown, and
- logical/physical camera identity change.

No diagnostic may turn an unconfirmed lock into success or block normal photo import fallback.

The exhaustive emitted-code list is in `docs/agents/contracts/015.md`; it includes backend
omission/cancellation, command cancellation, metering-point mapping, and focus-cancel failures in
addition to the primary codes.
