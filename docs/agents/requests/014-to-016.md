# Agent 014 → Agent 016: token-bound live analysis use case

- Requesting agent: **014 — Camera session identity, lifecycle and permission recovery**
- Receiving agent: **016 — Live capture analysis and frame ownership**
- Supplying source commit: `__SOURCE_SHA__`
- Target path/symbol: Agent 016's analysis implementation; contribute its CameraX `ImageAnalysis` through `CaptureSessionExtension.useCases`.

## Problem and reproducer

A live-analysis owner that binds separately, retains `ImageProxy` objects, or publishes an old frame result after Back can leak CameraX resources and display guidance for a replacement project/session.

Reproducer: block one analyzer result, close session A, open session B, then release the blocked result. The old proxy must close and no session-B state may consume the session-A result.

## Agreed interface, units and lifetime

- Construct the analysis `UseCase` before Agent 014 binds the session and expose it in `useCases`.
- Do not bind/unbind the provider independently.
- Every frame/result carries or closes over the immutable `sessionToken`; discard results after `onCameraUnbound` or token replacement.
- Close every `ImageProxy` exactly once on success, rejection, exception and cancellation.
- Keep analyzer backpressure and buffer ownership bounded; never retain full-resolution frames across the session without an explicit budget.
- Publish observed guidance/quality evidence only; no false capture-success state.

## Minimal adapter sketch

```kotlin
class LiveAnalysisExtension(...) : CaptureSessionExtension {
    override val useCases = listOf(imageAnalysis)
    override fun onCameraBound(identity: CaptureSessionIdentity, camera: Camera) {
        activeToken.set(identity.sessionToken)
    }
    override fun onCameraUnbound(sessionToken: String) {
        activeToken.compareAndSet(sessionToken, null)
        analyzer.cancelAndCloseOutstandingFrames(sessionToken)
    }
}
```

## Affected tests

- bounded backpressure and exact proxy closure
- delayed analysis result after Back/replacement
- pause/resume and rotation with the same identity
- no independent CameraX provider ownership
