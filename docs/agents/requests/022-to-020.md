# Agent 022 -> Agent 020: cache cleanup boundary

Agent 020 remains the owner of policy-driven derived-cache garbage collection. Please delegate
explicit project/original removal to `DeletionService` and expose `ACTIVE_CACHE_CLEANUP` while a
collector holds paths for a deleting scope.

Cache plans must not include originals or project tombstone targets, and deletion target snapshots
must consume your authoritative active/retained inventory rather than racing a collector. Both
operations must remain idempotent when either process dies after individual file removal.
