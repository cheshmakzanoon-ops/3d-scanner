# Agent 026 → Agent 021 integration request

- Requesting agent: 026
- Receiving agent: 021
- Source commit: `PENDING_AGENT_026_IMPLEMENTATION_COMMIT`
- Target path/symbol: storage admission for optional export staging

## Problem and reproducer

Some document providers may support an app-owned local or provider temporary document before
final commit. Such staging can temporarily duplicate the full export. It must not bypass the
shared storage budget or be inferred from provider capability flags.

## Agreed interface

When a future `DestinationDocumentStore` implementation stages locally, request an Agent 021
reservation for expected source bytes plus documented overhead before preparation. Hold the
reservation through commit/abort and release it on every success, failure and cancellation.
Unknown sizes must be rejected or admitted conservatively. The current direct SAF adapter does
not create local staging.

## Minimal adapter pseudocode

```kotlin
val reservation = storageBudget.reserveExport(source.expectedByteCount, operationId)
return StagedPreparedDestination(reservation, ...)
```

## Affected tests

- Agent 021 concurrent reservation/disk-full/process-recovery tests.
- Agent 026 storage-full and cancellation cleanup scenarios.
