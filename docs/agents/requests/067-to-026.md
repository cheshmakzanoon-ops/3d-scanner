# 067 → 026: implemented SAF coordinator integration

Consumer: `agents/067-export-coordinator`,
`export/SafExportCoordinator.kt`. Supplier: Agent 026 pinned source
`14be63f8760aa7b497f2e56df649b4cccc0adf3e`,
`data/safexport/{SafExportContracts,SafTransferPorts,FileVerifiedExportSourceAccess,DestinationTransferService}.kt`.

The bridge now consumes the actual 026 production services rather than asking
026 to implement the old `ExportDestination` copy adapter. `selection(request)`
validates the real catalog and binds the complete immutable request in a bounded
picker ledger. The returned `DestinationSelectionRequest` is CREATE_NEW_DOCUMENT;
request-ID, empty-destination, ownership and same-ID changed-format/options results
are rejected before provider access. A pre-existing destination is never opened
or deleted by this create-only flow. `abandon(requestId)` releases a cancelled
picker. After recreation, 071 must restore the exact PendingExportStore request
and call `selection(restoredRequest)` without relaunching the picker, then handle
its original callback.

`transfer(fixedRequest, callback, DestinationDocumentStore, cancelled, progress)`
materializes only into a new private staging file, applies the declared byte
budget before materialization, validates and hashes the completed staged bytes,
and checks source revision/currentness again. `FileVerifiedExportSourceAccess`
resolves that staged file only after `source.isCurrent` on every verify/open.
`DestinationTransferService` owns provider writing, readback, commit, cancellation
and cleanup. `SafCoordinatorOutcome.Transferred` preserves its exact
`VerifiedSuccess`, `CompletedUnverified`, `Cancelled` or `Failure`; provider close
or a matching size is never promoted to exact-byte verified success. Source,
project files and master geometry remain untouched. Private staging is removed
after all normal outcomes and coroutine cancellation.

picker URI, maintain the immutable pending request, preserve honest unverified
completion warnings and serialize the global project operation. This coordinator
provides a local duplicate/active guard and does not substitute for owner 001/006
project leases. 004 must include the pinned 026 source in the integrated app;
foreign code is not copied into 067's branch.
