## Problem and reproducer

Direct ViewModel export opens an artifact path and only checks the project after copying. It
does not provide a reusable canonical source resolver or operation lease. Agent 026 regressions
reject source identity/hash changes before copy, after copy and after provider commit.

## Agreed interface

Provide an adapter outside Agent 026's package that resolves the fixed
`ExportSourceIdentity(projectId, revision, artifactKey, representation)` to a canonical private
file plus the same identity. Feed it to `FileVerifiedExportSourceAccess`. The operation must
participate in Agent 006's export/project lease so deletion/publication cannot swap the path
while a stream is open.

Do not add format encoding to the adapter. Agent 067/025 supplies the committed source and
expected SHA-256/length; Agent 023 determines whether it is verified/current.

## Minimal adapter pseudocode

```kotlin
ExportSourceFileResolver { identity ->
    lease.withValidatedResult(identity) { artifact ->
        ResolvedExportFile(identity = artifact.identity, file = artifact.canonicalFile)
    }
}
```
