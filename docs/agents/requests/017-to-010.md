# Agent 017 → Agent 010: typed diagnostics mapping for live guidance

- **Requesting agent:** 017 (`agents/017-capture-overlap-guidance`)
- **Receiving agent:** 010 (`agents/010-diagnostics-contract`)
- **Source commit:** `a701783c724d7c490b17b33b327bf5a7b36c137a`
- **Requested target owner path:** `app/src/main/java/com/realityforge/scanner/engine/diagnostics/`
- **Supplying symbols:** `GuidanceObservation`, `GuidanceIngestResult`, `GuidanceReasonCode`, `GuidanceRejectionReason`

## Problem and reproducer

Live guidance now exposes stable evidence/action/reason enums, but diagnostics ownership belongs to Agent 010. Free-text conversion would lose unknown/stale-session semantics and could falsely imply whole-object completeness.

## Required mapping

Add an owner-side adapter that records bounded, versioned diagnostic events from `GuidanceObservation` and rejection results while preserving:

- `session(projectId, revision, sessionToken)`, `observedAtNanos`, `updateSequence`;
- outcome, `ImageOverlapState`, `GeometricConfidence`, action and reason enum names;
- exact evidence IDs and retained-summary counts;
- `objectCoverage == UNKNOWN_NOT_MEASURED` as unknown/null coverage, never zero or a percentage;
- `STALE_SESSION`, `NO_ACTIVE_SESSION` and `OUT_OF_ORDER_EVIDENCE` as distinct ignored/rejected causes rather than user-visible scan failures.

The adapter must not persist image buffers, descriptor arrays, private file paths or photographs. Retention must follow Agent 010's bounded event policy. UI/localization text remains outside this diagnostic record.

## Failure and unknown semantics

No pair evidence is `UNKNOWN`/`WAIT_FOR_MATCH_EVIDENCE`, not failure. Low overlap, repeated view, pure rotation, moving object and quality limitation are measured guidance outcomes, not reconstruction completion claims. A new session/retry may restart guidance `updateSequence`; it is monotonic only within one immutable capture session.

## Suggested verification

- JSON/typed round-trip retains every enum and evidence ID.
- Unknown object coverage cannot serialize as `0`, `false-complete` or a progress percentage.
- Bounded retention and redaction tests reject private paths/pixel payloads.
- Existing M19 `ScanQualityEvidence` behavior remains unchanged.
