# Handoff 010 → 055: topology evidence

Please expose measured `boundaryEdges`, `nonManifoldEdges`, `connectedComponents` and `selfIntersections` together with the topology classification and tolerance/version identity.

C9 reports leave every unavailable topology measurement `null`. `VERIFIED_WATERTIGHT` is accepted only when measured boundary and nonmanifold edge counts are both zero; a closed-looking render or missing measurement is not sufficient.
