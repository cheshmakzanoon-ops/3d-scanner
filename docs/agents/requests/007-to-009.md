# Agent 007 → Agent 009: supply real checkpoint validation for recovery

- **Requesting agent:** 007 — Persistent reconstruction jobs and recovery ledger
- **Receiving agent:** 009 — Artifact identity, stage manifests and safe checkpoint reuse
- **Source commit:** `4460d56109d8f6dae637996b645549e4490fa79b`
- **Target owner path/symbols:** `app/src/main/java/com/realityforge/scanner/engine/artifacts/`; Agent 009 manifest/checkpoint verifier

## Problem and reproducer

The job ledger deliberately stores only a coarse accepted-stage cursor plus checkpoint identity and SHA-256. It cannot decide whether a stage artifact is complete, representation-compatible, parent-linked, or safe for the current input. `DurableJobStoreRecoveryDeviceTest` validates actual file bytes before returning a recovery cursor and falls back to `CREATED` when validation fails.

## Agreed interface

Implement a `JobCheckpointValidator` adapter that:

- binds the candidate to the exact `JobInputSnapshot.identityKey()` and current project revision;
- rejects unknown manifest versions, incomplete artifacts, absent/truncated files, size/hash mismatch, wrong representation, invalid parent identity, and engine/settings/calibration mismatch;
- verifies actual bytes, not only a database flag or filename;
- returns `ResumeFrom(cursor)` only for the same immutable `JobStageCursor` or a verified earlier stage; it must never invent a later stage or replace a checkpoint at the same stage;
- otherwise returns `RestartFromBeginning(STABLE_UPPERCASE_CODE)`; validation exceptions must not mark success;
- keeps manifest/path ownership in Agent 009—Agent 007 stores only stable identity and checksum fields.

All hashes are lowercase SHA-256 hex; byte sizes are bytes; times are not part of artifact identity unless explicitly versioned by Agent 009.

## Minimal adapter pseudocode

```kotlin
val validator = JobCheckpointValidator { snapshot ->
    val verified = verifier.verify(
        checkpointIdentity = snapshot.cursor.checkpointIdentity,
        expectedSha256 = snapshot.cursor.checkpointSha256,
        expectedInputIdentity = snapshot.identityKey,
        expectedStage = snapshot.cursor.acceptedStage,
    )
    if (verified != null) CheckpointRecoveryDecision.ResumeFrom(snapshot.cursor)
    else CheckpointRecoveryDecision.RestartFromBeginning("CHECKPOINT_INVALID")
}
```
