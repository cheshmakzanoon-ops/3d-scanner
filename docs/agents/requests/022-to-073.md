# Agent 022 -> Agent 073: photo review permanent-delete action

Please keep ordinary photo exclusion in curation. A separate permanent-delete action must bind a
fixed project/photo/revision to `DeletionIntent`, require explicit confirmation, then consume
`PendingDeletion` and retry state. Returning from a dialog or changing projects cannot delete the
new selection.

External source photographs are never targets; only the imported private copy and exclusively
owned derived references may be removed.
