# Agent 022 -> Agent 072: library deletion UI state

Please consume `PendingDeletion`/`DeletionRunResult` rather than treating delete as an immediate
boolean. Confirmation dismissal performs no mutation. After confirmation, keep the scoped item
visible as pending/waiting/retryable until `COMPLETED`, show typed destructive scope, and expose a
retry action without displaying private paths.

Large text, rotation, keyboard and TalkBack must preserve the confirmation boundary and distinguish
photo exclusion from permanent deletion.
