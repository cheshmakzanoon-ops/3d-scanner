# Handoff 010 → 009: exact artifact and job identity

Please expose the following C8 values when constructing the C9 report:

- explicit durable `jobId` and positive `jobAttempt`;
- source project revision;
- artifact ID and representation kind;
- engine and settings identities.

`ScanQualityReport` currently derives `artifact:<artifactId>` when no explicit job ID exists and labels that identity `DERIVED_FROM_ARTIFACT`. Replace the derived scope only after C8 supplies a validated explicit job scope. Imported diagnostics with expected identity must fail when these values are absent or mismatched.
