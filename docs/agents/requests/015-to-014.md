# Agent 015 → Agent 014 integration request

Agent 014 owns `CameraScreen.kt` and capture lifecycle/session identity.

Please integrate the contract in `docs/agents/contracts/015.md` by:

1. Reading capabilities for the selected logical camera.
2. Selecting and retaining one physical camera ID (or explicit logical-only mode) for the full
   capture session.
3. Applying `CameraXOpticsInterop` to Preview and ImageCapture builders before binding.
4. Supplying the immutable Agent 014 session token and a preview metering-point mapper to
   `CameraOpticsController`/`CameraXOpticsBackend`.
5. Calling `unbind` before permission-loss, lifecycle-disposal, or rebind teardown.
6. Rendering `ACKNOWLEDGED_UNCONFIRMED` as pending confirmation, never as a locked state.

Do not copy the controller into `CameraScreen`; consume the package contract directly. Add the
late-callback/rebind screen regression in Agent 014's owned tests.
