# Agent 017 → Agent 014: camera-session wiring and guidance rendering

- **Requesting agent:** 017 (`agents/017-capture-overlap-guidance`)
- **Receiving agent:** 014 (`agents/014-camera-session-lifecycle`)
- **Source commit:** `a701783c724d7c490b17b33b327bf5a7b36c137a`
- **Requested target owner paths:** `ui/CameraScreen.kt` and `capture/session/`
- **Supplying symbols:** `CaptureGuidanceCoordinator`, `CaptureSessionIdentity`, `GuidanceFrameIdentity`, `GuidanceObservation`

## Problem and reproducer

Agent 017 intentionally does not edit CameraScreen. Without owner wiring, real guidance cannot enter the continuous capture session and a delayed matcher callback could render advice for a different project/session.

## Requested integration

- Create one `CaptureSessionIdentity(projectId, revision, sessionToken)` from Agent 014's immutable session state and call `beginSession`/`endSession` at the same lifecycle boundaries.
- Stamp frame, quality and motion evidence with `SystemClock.elapsedRealtimeNanos()` from one monotonic clock and strictly increasing per-session frame sequence numbers.
- Run `CaptureGuidanceCoordinator.compare` on a bounded analysis executor; never on the Compose/main thread and never retain preview image buffers in UI state.
- Render a `GuidanceObservation` only when its complete session identity equals the active CameraScreen session. Dispose/cancel callbacks on Back, permission loss, rebinding or session replacement; stale arrivals are ignored as `STALE_SESSION`.
- Keep saved-photo counts and guidance separate. Do not derive a monotonic coverage ring or whole-object percentage from count, overlap or advice history.

Initial/no-pair state should show wait-for-evidence unobtrusively. Outcome/action/reason enums are passed to Agent 075/078 copy resolution; CameraScreen must not hard-code technical enum strings.

## Required tests

A controllable delayed matcher after Back/project switch cannot update the new screen; frame sequence replay is rejected; rotation/rebind keeps one valid session or deliberately starts a clean one; repeated shots do not leak executors/buffers; static capture remains functional when guidance/matcher/analyzer is unavailable.

Run `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` and `connectedDebugAndroidTest`; physical multi-shot guidance remains a separate device gate.
