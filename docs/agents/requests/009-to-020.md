# Agent 009 → Agent 020: manifest-reachability garbage collection

Treat current and last-completed `StageManifest` records plus active attempt leases as GC roots. Traverse dependency manifest hashes and artifact relative paths. Delete only unreachable derived artifacts after decoding bounded known versions and confirming no active lease references them.

Invalid/corrupt/unknown manifests must be quarantined for recovery diagnostics, not interpreted as an empty root set. Preserve originals. M18 `.depth-checkpoints-m18` cleanup remains compatible until Agent 050 publishes a successor format.
