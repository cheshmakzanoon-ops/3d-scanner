## Problem and reproducer

Agent 017's state machine is complete against deterministic replay evidence, but production guidance must not infer matches, pose, parallax or object motion from photo count or UI state. A production `PipelinePairEvidenceProvider` must obtain the real matcher/pose evidence for the exact immutable feature and calibration artifacts named by each `PipelineGuidanceFrameReference`.

## Required interface

Implement an owner-side provider for:

```kotlin
fun interface PipelinePairEvidenceProvider {
    fun compare(
        reference: PipelineGuidanceFrameReference,
        candidate: PipelineGuidanceFrameReference,
    ): PipelinePairEvidence
}
```

The returned DTO must preserve these units and meanings:

- match and inlier fields are non-negative counts from the actual feature/matching/geometric-verification path;
- `occupiedImageCells / totalImageCells` is image-grid support only, never object coverage;
- displacement is pixels divided by the larger image dimension;
- rotation and parallax are degrees;
- translation is relative translation norm divided by robust positive scene depth;
- reprojection error is in normalized camera coordinates;
- dynamic outliers are a `[0,1]` fraction rejected as inconsistent with one rigid scene.

`evidenceId` must identify the exact pair/artifact/algorithm result. A validated pose uses `ESSENTIAL_POSE`. Both references must resolve to immutable artifacts under one canonical `calibrationIdentity`; mismatch or unavailable/stale artifacts must not be converted into successful geometry. Do not invoke the guidance matcher until valid pair evidence exists; report pipeline failures through Agent 010 rather than fabricating zero-valued success.

## Lifetime and execution

Run `compare` off the main thread on the bounded analysis/pipeline executor. The guidance coordinator retains only the returned summary; image buffers, descriptors, OpenCV Mats and native handles remain owned and released by the pipeline. A session change after matching is rejected by Agent 017's session identity checks.
