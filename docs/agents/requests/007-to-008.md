# Agent 007 → Agent 008: make JobStore authoritative for runner lifecycle

- **Requesting agent:** 007 — Persistent reconstruction jobs and recovery ledger
- **Receiving agent:** 008 — Android long-running execution and platform lifecycle
- **Source commit:** `4460d56109d8f6dae637996b645549e4490fa79b`
- **Target owner path/symbols:** `app/src/main/java/com/realityforge/scanner/work/execution/`; runner/service lifecycle and stop/timeout handling

## Problem and reproducer

The current process-local execution path can disappear with the activity or process. A runner that caches only a job ID, attempt number, or old `JobLease` can continue after renewal, pause, timeout, recovery, or retry and attempt to publish stale work. `DurableJobStoreLeaseDeviceTest` reproduces this by renewing/relinquishing and proving the superseded lease cannot complete.

## Agreed interface

- Call `acquireNext(workerId, nowEpochMillis, leaseDurationMillis)` to begin an attempt.
- Treat the returned `JobLease` as an opaque, single-version capability containing job ID, attempt, token, worker ID, absolute epoch-millisecond expiry, and state version.
- After every `renew`, `acceptStage`, or persisted `recordProgress`, replace the in-memory lease with the returned `LeasedJob.lease`; the previous lease is stale immediately.
- Before every filesystem publication boundary, call `validateLease` and pass that exact validated lease to Agent 023.
- On supported service stop/timeout/task removal, stop native work and call `relinquish(lease, stableReasonCode, now)` while the lease is still valid. Do not silently queue or complete with an expired lease.
- On process start, call `recoverExpired` with Agent 009's real artifact validator. Recovery leaves work `PAUSED`; explicit resume followed by acquisition creates the next monotonic attempt.
- Pause/resume/retry/cancel are idempotent user commands keyed by stable `JobId`; never derive the target from the currently selected project.

## Minimal adapter pseudocode

```kotlin
var active = store.acquireNext(workerId, clock.nowMillis(), leaseDuration) ?: return
try {
    active = store.acceptStage(active.lease, acceptedCursor, clock.nowMillis())
    active = store.recordProgress(active.lease, coarseProgress, clock.nowMillis())
    val fenced = store.validateLease(active.lease, clock.nowMillis())
    publication.publish(fenced, active.lease, stagedArtifacts)
} catch (stop: SupportedRunnerStop) {
    native.cancelAndJoin()
    store.relinquish(active.lease, stop.stableCode, clock.nowMillis())
}
```
