## Problem and reproducer

Guidance may combine quality/motion with pair geometry only when session identities and monotonic timestamps agree. Reusing the latest analyzer value without temporal association can incorrectly label a later view blurry, moving or safe.

## Requested adapter

Expose owner-side mapping into Agent 017's summary-only DTOs:

- same immutable `CaptureSessionIdentity` supplied by Agent 014;
- `timestampNanos` from the same elapsed-realtime clock as `GuidanceFrameIdentity`;
- quality state `UNKNOWN | ACCEPTABLE | BLUR_RISK | EXPOSURE_RISK` with confidence `[0,1]` or null for unknown;
- motion state `UNKNOWN | STABLE | CAMERA_SHAKE | SUBJECT_MOTION` with measured confidence and optional non-negative angular velocity in degrees/second.

Do not pass `ImageProxy`, bitmap, YUV planes, gyro buffers or analyzer-owned objects. Unknown/unsupported/analyzer-failure state remains unknown and must not block normal capture. Agent 017 associates only signals within `signalAssociationToleranceNanos`; temporally distant risks may be disclosed only as stale context and cannot be listed as evidence used for the current classification.

## Required tests

Use a fake monotonic clock to prove near signals affect the intended candidate, distant acceptable signals do not clear risk, distant risks are labelled as different-time context, stale sessions are rejected, and every ImageProxy lifecycle remains owned/closed exactly once by Agent 016.
