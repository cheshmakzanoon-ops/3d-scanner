## Original literal gaps

Actual UI exports bypassed the pure transfer helper. The Android adapter test only rejected file://; the required shared fault DocumentsProvider and actual provider matrix were missing. Late stream errors and stalled/excess readback needed fixes.

## Implemented behavior and integration

Root connected artifact/archive export to immutable requests, exact project/revision/artifact, C6 access, verified 023 sets or strict legacy validation, 021 budgets and owned staging. Production transfer verifies source bytes, bounds copy/readback and maps late write/flush/close failure. VerifiedSuccess requires exact readback; unavailable verification remains CompletedUnverified with explicit non-atomic provider behavior. Cleanup only affects newly created owned documents. Added the single shared test-only qa/FaultDocumentProvider at reserved 088 path, retaining the existing 011 test provider. Its real ProxyFileDescriptorCallback supports short writes, silent truncation, ENOSPC, revoked/unavailable access and exact success under bounded documents. Setup uses narrow grants; transfer runs under normal application authority.
