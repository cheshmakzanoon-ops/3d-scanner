## Original literal gaps

Profile/session contracts were not connected to a durable Room mutation journal or complete runtime optical compatibility. Partial image/native allocation and duplicated rejected-view reporting also needed correction.

## Implemented behavior and integration

Connected full accepted/rejected-view measurements and measurable diversity to the existing checkerboard math. Metadata namespaces source/device/camera/lens; unknown zoom/crop stays unknown and imported EXIF stays unverified. Added calibration_mutations with expected revision/profile hash and C6 profile publication: canonical staging, synced journal/prior backup, atomic promotion/removal and a narrow protected Room commit. Recovery matches exact old/new hashes, preserves ambiguous data and is idempotent. Actual 001/002 workflow consumes canonical optical compatibility before reconstruction; completed output becomes stale and original bytes are preserved. Finally blocks close partial OpenCV/image ownership. No new physical calibration accuracy is claimed.
