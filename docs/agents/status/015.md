## Implemented

- Bounded, platform-neutral `CameraCapabilities`, `OpticalControlRequest`,
  `AppliedOpticsState`, and result metadata contracts.
- Camera2/CameraX capability interpretation for physical IDs, focus modes, AF/AE/AWB regions,
  AE/AWB locks, zoom, exposure compensation, JPEG sizes, focal lengths, active array, and
  stabilization. Missing keys remain unavailable.
- Session-bound command controller with serialized requests, bounded timeouts, explicit
  pending/acknowledged/applied/unavailable/failed states, and generation checks that discard
  late completions after rebind, unbind, or permission loss.
- AE/AWB lock application through Camera2 interop with capture-result confirmation. A completed
  control future without matching capture metadata remains `ACKNOWLEDGED_UNCONFIRMED`.
- Camera2 result observer recording logical/active physical camera, focal length, zoom/crop,
  exposure, ISO, aperture, focus distance, locks, timestamp, and frame number.
- Physical camera pinning helpers for Preview/ImageCapture builders and detection of unexpected
  physical-lens changes within a session.
- Compose-ready UI model and explicit handoff contracts for Agents 014, 013, and 010.
- Pure JVM regressions for unsupported controls, capability sanitization, manual-focus fallback,
  lock confirmation, stale completion/rebind/unbind, camera mismatch, physical-lens change, and
  disposed UI state.
- Android instrumentation source that reads actual device/emulator Camera2 characteristics
  without fabricating support.
