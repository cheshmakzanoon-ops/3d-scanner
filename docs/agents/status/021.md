## Original literal gaps

The assigned branch was still at the campaign base with no storage-budget implementation or receipt. A single fixed free-space check did not cover overlapping imports, reconstruction, export staging or durable claim recovery.

## Implemented behavior and integration

Added overflow-safe estimates for originals, analysis, features, depth, meshes, textures, staging and retained results. Unknown sizes remain explicit. Actual Room transactions bind each claim to its operation, project and revision, subtract other claims and a 64 MiB safety reserve, and retain an existing claim if recheck fails. Recovery preserves authoritative active and resumable work without an age-expiry shortcut. Import, archive, export and execution owners consume admission, boundary rechecks and terminal release. The coordinator added the exact rejected SpaceDecision and ReservationToken to a StateFlow for matching storage UI. Reclaimable bytes are advice, never assumed free space.
