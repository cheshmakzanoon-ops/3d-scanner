## Original literal gaps

The branch had no assigned implementation. Arbitrary JSONObject geometry reached Compose and both diagnostic viewers parsed/allocated it there. Initial integration also chose an older publication.previous when current was already the latest completed result behind advanced inputs.

## Implemented behavior and integration

Added strict typed adapters for sparse schemas 1/3/6 and dense/mesh/texture 7/8/10, with identity, finite coordinates, types/counts/colors/indices and explicit capabilities/unavailable reasons. Strict UTF-8, 32 MiB JSON, nesting/stall limits and point/vertex/triangle/atlas caps bound reads before display allocation. Reopening checks project identity before/after and rehashes actual preview bytes against the verified manifest. Advanced inputs expose the latest completed current set only through previous selection; corrupt latest output does not silently fall back. Immutable private geometry buffers are normalized/sampled off main with cancellation; both diagnostic viewers accept prepared buffers only, preserving x/-y/-z display convention. Diagnostic compatibility labels remain bounded/validated; photographic GLB validation stays with 068. Root consumes prepared geometry by immutable selected identity and shows an explicit read-only earlier result.
