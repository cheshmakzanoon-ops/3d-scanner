## Implemented behavior and integration

Added version 2 streaming ZIP with final completion manifest, declared version 1 read support, exact original length/SHA, canonical member whitelist, duplicate/traversal/inflation/member/count limits and current BuildConfig version. C6 export leases and 021 staging budgets are used. Restore validates an isolated owned directory, rebinds project/photo IDs, syncs intent/ownership marker, promotes it and publishes all rows in one Room transaction. Locked/idempotent recovery cleans only identified uncommitted ownership and preserves committed/foreign data. Hash-bound bounded sidecars preserve canonical capture metadata/optical identity, observed settings, curation, quality and order. Pending-removal request IDs are renewed so old confirmation cannot delete an independent restoration. Source provenance is retained without claiming physical verification.
