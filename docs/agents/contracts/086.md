# Physical inputs handoff

`tools/device/capture_validation/qualify.py discover|audit` emits version1 JSON and nonzero failure. Successful input audit supplies exact installed app/device identity, cameraId, original-byte hashes/JPEG orientation and independent checkerboard/reference hashes. It requires private local evidence files, hashes every referenced file, and rejects emulator/synthetic provenance. Raw objects/calibration/reference photos stay private.083–085/087–090 consume approved archived captures plus these manifests, preserving physical versus synthetic labels. Passing the input audit does not assert registration, completeness, accuracy or thermal budgets.
