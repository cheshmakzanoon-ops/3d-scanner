# Agent 016 — bounded live capture quality contract

Source implementation commit: `60504f3d1c779156813babf6f293b231a04b12d6`

## Scope

This contract exposes bounded, session-scoped blur, exposure, contrast and inter-frame-change evidence. It does not estimate object coverage, reconstruction completeness or an overall quality percentage. The implementation is offline and retains at most one downsampled luma frame.

Production symbols are under `com.realityforge.scanner.capture.analysis`.

## Session and observation identity

- `CaptureAnalysisSessionId.value` is a nonblank opaque token, at most 128 characters. Agent 014 supplies one new token for each camera-session generation.
- `CaptureQualityObservation.sessionId` must exactly match the active camera session before a UI or downstream analyzer consumes it.
- `sequence` starts at 1 and increases only for frames admitted for analysis. Cadence- and out-of-order-dropped frames do not advance it.
- `frameTimestampNanos` is the CameraX image timestamp in nanoseconds. It is for ordering within a session; consumers must not treat it as wall-clock time.
- `observationId` is unique within the session and currently has the form `<session>:<sequence>:<timestamp>`; consumers must treat it as opaque.
- `sourceRotationDegrees` is one of `0`, `90`, `180`, or `270`; the luma metrics are computed after upright rotation.

## Observation semantics

`CaptureQualityObservation` contains:

- `status`: `WARMING_UP`, `ACCEPTABLE`, `ACTION_REQUIRED`, or `UNAVAILABLE`.
- `action`: typed guidance (`WAIT_FOR_EVIDENCE`, `READY_TO_CAPTURE`, `HOLD_STEADY`, `ADD_LIGHT`, `REDUCE_LIGHT`, `EVEN_OUT_LIGHTING`, or `REFOCUS_OR_REFRAME`).
- `confidence`: `0.0..1.0` confidence in the bounded measurements only, never a scan-quality or completeness percentage.
- `metrics`: normalized luma evidence. It is null only when analysis is unavailable because the frame exceeded the active budget.
- `evidenceCodes`: nonempty typed reasons suitable for deterministic presentation or composition with another measured signal.
- `thresholdSource` and `thresholdEvidenceIds`: whether conservative defaults or accepted retained-photo evidence produced the thresholds. Retained-photo IDs are opaque provenance IDs.

Consumers must preserve `UNAVAILABLE` and `MOTION_UNAVAILABLE` as unknown evidence. They must not translate either state into a positive capture recommendation.

## CameraX ownership and lifecycle

- `CameraXCaptureQualityAnalyzer` owns every `ImageProxy` passed to `analyze` and calls `close()` exactly once from its `finally` path, including success, cadence rejection, invalid/unsupported input, cancellation, observer failure and disposed-session paths.
- `CameraXLumaFrameReader` only borrows the proxy and plane buffer during `read`; it never closes or retains them.
- `CaptureQualityImageAnalysis.create(executor, targetRotation, analyzer)` creates a YUV `ImageAnalysis` use case with `STRATEGY_KEEP_ONLY_LATEST`. Agent 014 owns binding/unbinding and executor lifecycle.
- `CameraXCaptureQualityAnalyzer.close()` is idempotent. After it returns, no new observation or failure callback is published, retained frame state is cleared, and later proxies are still closed.
- Callbacks are synchronous on the ImageAnalysis executor. Callback exceptions are contained and reported as `OBSERVER_FAILURE`; they never escape to CameraX.
- `stateSnapshot()` is a bounded diagnostic snapshot for integration tests and later resource qualification. It exposes analyzed/dropped/rejected counters, one-frame retention bytes, last admitted timestamp and closed state.

## Budget contract for Agent 030

`CaptureAnalysisBudgetProvider.currentBudget()` is read before YUV extraction and again by the stream analyzer. It must be fast, nonblocking and return a valid immutable `CaptureAnalysisBudget`:

- `maxAnalysisEdge`: `64..1024` pixels.
- `minFrameIntervalNanos`: `33_000_000..2_000_000_000` ns.
- `maxRetainedFrameBytes`: `4_096..1_048_576` bytes.
- `actionConfirmationFrames`: `1..8`.
- `readyConfirmationFrames`: `1..12`.

A runtime budget shrink immediately drops retained evidence that no longer fits and resets smoothing. A provider failure is contained as `ANALYZER_FAILURE`; normal camera capture must remain usable.

## Threshold contract

`CaptureQualityThresholdProvider.currentProfile()` returns conservative defaults or a profile derived from accepted retained photographs. `CaptureQualityThresholdDeriver` ignores rejected photographs, duplicate evidence IDs and insufficient sample sets. Threshold evidence is provenance, not ground truth.

## Minimum integration checks

1. Start session A, publish an observation, end A, start B, and prove an A observation cannot render in B.
2. Close or rebind while a frame reader is active and prove no stale callback is published and the proxy closes exactly once.
3. Exercise rotation plus nontrivial crop, row stride and pixel stride.
4. Shrink the dynamic budget and prove retained bytes remain within the new bound.
5. Keep capture available after every typed analyzer failure.
