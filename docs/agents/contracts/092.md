# Agent092 runner contract

`bash tools/run-device-tests.sh --serial SERIAL --app-apk APP.apk --test-apk TEST.apk --output DIRECTORY [--expect-api N] [--expect-abi arm64-v8a|x86_64] [--expect-page-size 4096|16384]` uses prebuilt APKs and returns 0 only after nonzero passing instrumentation and a fresh decoded full-session PNG. With no arguments it builds first and requires exactly one authorized device. Reports are compatibility.json, instrumentation.txt, photographic-viewer.png. Missing devices/screenshots/zero tests/candidate/environment mismatches return nonzero. No uninstall or data clearing. CI093 may invoke the script directly with exact candidates and serial. Artifact hashes and runtime16kb/physicalCapture gate distinctions are in JSON. Device tests require a disposable installation because existing instrumentation creates/deletes test projects.
