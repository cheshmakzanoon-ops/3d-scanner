# 054 observed normal and local uncertainty

Header-only `estimateObservedNormal(span<NormalObservation>,query,settings)`
fits bounded covariance through actual point positions. Each observation carries
its camera center, stable observation ID and optional `weight` defaulting to 1.
Weight must be finite in (0,1]; it is relative reliability, never calibrated
inverse variance. `ObservedNormal.validity` explicitly
reports Supported/SparseSupport/Discontinuity/IllConditioned/Invalid; absent
support is not a zero-error measurement. Direction faces the nearest supporting
camera. Returned IDs refer to actual retained support.

`estimateDepthNeighborhoodNormal(view,map,x,y,step,maxRelativeJump)` uses the
nine real camera-z neighbors, rejects missing/discontinuous windows and converts
world-to-camera row-major poses through the tested inverse. It never bridges
an occlusion or fills a depth hole. After all nine depths pass the existing
jump gate, the covariance query radius encloses their actual world distances.
A frontoparallel pixel footprint must not truncate a complete slanted neighborhood.
Radius construction uses the exact same bounded distance arithmetic as neighbor
filtering, rounded outward; mixing hypot and sqrt(dot) had lost one boundary
sample in the scale-100 synthetic outlier case despite nextafter rounding.
All nine observations remain subject to the unchanged residual, conditioning and
minimum-support checks. The depth adapter requires a confidence array matching
the depth array and reads the actual confidence at every selected pixel. All
nine depth/jump checks precede confidence handling: any zero confidence makes
the entire window SparseSupport, while nonfinite/negative/>1 confidence is an
input error. No zero/low-confidence neighbor is silently removed.

The fixed reliability rule divides positive selected weights by their maximum,
then computes W=sum(w), center=sum(w*p)/W and covariance=
sum(w*(p-center)*(p-center)^T)/W. Equal weights exactly preserve the prior
unweighted fit, including tiny common weights. `effectiveSupport` reports Kish
W^2/sum(w^2); support below the existing minimumNeighbors=5 is SparseSupport.
The existing smallest/middle eigenvalue maximum .08, middle/largest minimum .02,
relative-depth-jump maximum .08 and independent separated-residual-layer detector
remain unchanged. Before accepting nonuniform reliability, a second bounded
unit-weight fit preserves the original raw-support separated-layer rejection;
changing the weighted normal must not hide two previously separated layers.
An unweighted IllConditioned result alone does not veto the reliability fit.
The extra fit is limited to the already selected <=256 neighbors and stops at
unit weights, so at most two 32-rotation fits run. Every supported depth normal
still retains all nine IDs.

Plane residual, covariance conditioning and
estimatedPositionSigma are heuristic geometric evidence unless input noise is
explicitly calibrated; arbitrary world scale remains arbitrary. Nonuniform
reliability always forces calibrated=false, even if calibratedNoise was requested.
The depth adapter always returns calibrated=false. The uncertainty heuristic is
sqrt(smallestEigenvalue+observationSigma^2)/sqrt(effectiveSupport); it is not an
independent physical error estimate.

The predeclared analytic robustness fixture is a z=5 plane, focal=200, step=3,
with one actual corner depth 5.1 (2% jump), confidence 1/8 and the other eight
confidences 1. With all nine observations retained, unweighted covariance fails
the unchanged .08 residual ratio (.14550084); reliability covariance passes
(.04902711), effective support is 8.23586745 and truth-normal angular error drops
20.22980 to 3.92578 degrees. A 1% outlier improves 9.31183 to 1.87799 degrees
while both fits are already supported. These synthetic cases establish behavior
when confidence correctly identifies less reliable depth; they do not calibrate
photometric confidence or predict held-out reconstruction completeness. The rule
and fixtures are committed before any real-photo evaluation of this change.

Hard bounds cover input observations, chosen nearest neighbors and 32 Jacobi
iterations per fit (at most two fits); cancellation is checked during covariance
eigen iterations and scans.
The estimate is distinct from area-weighted final mesh normals. Fusion may use
orientation compatibility but must preserve unsupported samples separately.
