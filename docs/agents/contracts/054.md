# 054 observed normal and local uncertainty

Header-only `estimateObservedNormal(span<NormalObservation>,query,settings)`
fits bounded covariance through actual point positions. Each observation carries
its camera center and stable observation ID. `ObservedNormal.validity` explicitly
reports Supported/SparseSupport/Discontinuity/IllConditioned/Invalid; absent
support is not a zero-error measurement. Direction faces the nearest supporting
camera. Returned IDs refer to actual retained support.

`estimateDepthNeighborhoodNormal(view,map,x,y,step,maxRelativeJump)` uses the
nine real camera-z neighbors, rejects missing/discontinuous windows and converts
world-to-camera row-major poses through the tested inverse. It never bridges
an occlusion or fills a depth hole. After all nine depths pass the existing
jump gate, the covariance query radius encloses their actual world distances.
A frontoparallel pixel footprint must not truncate a complete slanted neighborhood.
All nine observations remain subject to the unchanged residual, conditioning and
minimum-support checks. Plane residual, covariance conditioning and
estimatedPositionSigma are heuristic geometric evidence unless input noise is
explicitly calibrated; arbitrary world scale remains arbitrary.

Hard bounds cover input observations, chosen nearest neighbors and 32 Jacobi
iterations; cancellation is checked during covariance eigen iterations and scans.
The estimate is distinct from area-weighted final mesh normals. Fusion may use
orientation compatibility but must preserve unsupported samples separately.
