# 090 export evidence contract v1

`python -m tools.qa.export_interoperability.validate ASSET --expect EXPECTED.json
--roundtrip --output REPORT.json` emits schema 1 and exit 0 PASS / 1 FAIL / 2 NOT_RUN.
Actual path/SHA256, independent reader/version, geometry representation/bounds,
triangle/texture counts, Khronos issues and target-tool result are separate fields.
Without `--roundtrip`, target-tool is explicitly NOT_RUN. Missing dependencies never
become skips or passes. No Android/runtime exporter is modified.

Consumers 061–068/083/085/095/099/100 supply candidate artifacts with immutable hashes
and independent expected bounds, representation, material corner samples and units.
Texture sample positions use exported world axes; RGB bytes use decoded sRGB.
Expected scale must come from measurement provenance, not the output itself.
Input GLB subset is embedded resources, glTF2 POINTS/TRIANGLES; OBJ requires local
bounded safe MTL/image sidecars. PLY/STL are independently read through Trimesh.
Blender4.3 actual imports/exports preserve point locations and texture corners for
triangle fixtures. Point clouds are read-only validated and never qualified as mesh.
