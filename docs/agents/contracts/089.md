# Packaged privacy and runtime evidence contract v1

`tools/device/offline_privacy/audit.py` takes exact APK, SDK and full sourceSHA; exit0 means
only the compiled policy passed. It records APK SHA256 and keeps runtime/physical gates
NOT_RUN. Missing network/broad-gallery permission, camera optionality, explicit backup/
cleartext flags and every credential/device-protected backup/transfer domain are required.
Malformed aapt output is rejected. No source-only inference certifies a package.

`journey.py` uses explicit serial, candidate/testAPK hashes, app installation opt-in and
before/after radio settings. It requires three completed, unskipped real instrumentation
scenarios. No device, mixed settings, wrong test counts or failed instrumentation can pass.
The reconstruction scenario is labeled synthetic and does not qualify real captures.

Agent091 consumes package privacy assertions;095 reconciles actual dependencies;098 owns
shared public runbook links;099 must preserve packaged-policy PASS versus runtime/physical
NOT_RUN. Agent008 remains sole main-manifest owner. No runtime permission was added.
