# Packaged privacy and runtime evidence contract v2

`tools/device/offline_privacy/audit.py` takes exact APK, SDK and full sourceSHA; exit0 means
only the compiled policy passed. It records APK SHA256 and keeps runtime/physical gates
NOT_RUN. Missing network/broad-gallery permission, camera optionality, explicit backup/
cleartext flags and every credential/device-protected backup/transfer domain are required.
The manifest's numeric dataExtractionRules ID must resolve to one named XML resource
and one default file value in the actual aapt2 table. apkanalyzer's default value must
agree with that table path. The exact ZIP entry is unique and its bytes are hashed;
only this referenced XML is evaluated, including when R8/resource shrinking renames
it to res/4j.xml. Unknown IDs, aliases, qualified variants, duplicate IDs/names/ZIP
entries, mismatched paths and unsafe paths fail closed. A safe unreferenced original
cannot certify an unsafe referenced policy. Malformed aapt output is rejected.
No source-only inference certifies a package.

`journey.py` uses explicit serial, candidate/testAPK hashes, app installation opt-in and
before/after radio settings. It requires three completed, unskipped real instrumentation
scenarios: packagedAppHasNoNetworkPermissionAndOptionalCamera,
deletingAProjectPreservesExternalOriginalsExportsAndOtherProjects, and
explicitOfflineSyntheticImportReconstructionInspectionReopenExportJourney.
Each requires a unique full AndroidJUnitRunner start/success pair with the exact
OfflinePrivacyJourneyTest class, matching method, current1..3 and numtests3. Method
execution order may vary, Bundle field order may vary, and stream fields may span
lines. Missing/duplicate/unknown fields, foreign/duplicate methods, mismatched pairs,
skipped/failed status codes, incomplete Time/OK(3tests) summary or missing/non-success/
duplicate final INSTRUMENTATION_CODE:-1 fail. Naked terminal success counters never
establish completion. No device, mixed settings or failed instrumentation can pass.
The reconstruction scenario is labeled synthetic and does not qualify real captures.

Agent091 consumes package privacy assertions;095 reconciles actual dependencies;098 owns
shared public runbook links;099 must preserve packaged-policy PASS versus runtime/physical
NOT_RUN. Agent008 remains sole main-manifest owner. No runtime permission was added.
