# Bundle optimizer additive v1

Baseline `TwoAnchors` mode remains compatible. `BundleGauge::PoseAndBaseline` fixes full first world-to-camera pose and preserves the initial first-to-second camera-centre distance; the second pose can correct rotation/direction. Every trial is re-normalized about fixed camera0 before monotonic robust objective admission. World scale remains arbitrary. Per-point camera cross blocks are allocated only for actual observation adjacency. Supported local windows3..32 cameras,<=20000 points,<=100000 observations, default estimated working-set admission64MiB. Larger graphs must use explicit coordinator-supplied stable-ID windows;80/250 camera global solves fail before allocation rather than densifying unbounded equations. Estimation is conservative admission, not measured process RSS.

Result includes gauge mode, known allocated-work estimate, termination reason and per-camera median residuals; no-observation cameras currently receive0 residual and must be interpreted together with usable support. Native cancellation checkpoints use existing051 thread-local Scope. Exported C ABI is noexcept and contains both operation and error-serialization allocations; nullptr means allocation/unknown failure and caller must not dereference. Normal error JSON remains malloc-owned, rf_free releases it.
