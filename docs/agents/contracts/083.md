# Agent 083 corpus contract v1

`tools.qa.corpus.manifest.validate(dict, Path) -> dict` validates offline content
and raises `InvalidManifest(ValueError)` on invalid identity/provenance/units.
`tools.qa.corpus.fixture.generate(Path)` creates deterministic synthetic PNG/OBJ
and its manifest. Full executable example and acquisition policy:
`benchmarks/corpus/README.md`. No raw physical captures are committed.

Consumers 084–090/099 must bind manifest SHA256, candidate SHA256, source SHA,
settings SHA256, protocol SHA256 and per-scene results. Filter reconstruction
photos by `role == reconstruction`; held_out photos are evaluation only.
`reference.independent: true` records the operator's attestation; tooling never
pretends hashing proves physical truth. Synthetic kind is regression only.
Neither PASS input validation nor ELIGIBLE_INPUT_ONLY closes physical quality.
Schema versions other than 1 fail. Reference units must match dataset units.
