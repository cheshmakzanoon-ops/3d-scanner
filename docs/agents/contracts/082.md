# Bounded native/JNI regression contract v1

Standalone target graph: cmake -S reconstruction/fuzz -B build/fuzz -G Ninja -DCMAKE_CXX_COMPILER=CLANG -DCMAKE_BUILD_TYPE=RelWithDebInfo. Build only rf_fuzz_numeric,rf_fuzz_checkpoint,rf_fuzz_exports. Each uses actual shared reconstruction sources with ASan/UBSan and libFuzzer, fixed allocated buffer bounds and local temporary outputs. It also supports parent inclusion after target realityforge exists, with instrumentation enabled on that target.

`python tools/qa/fuzz/run.py --compiler CLANG --output PRIVATE_DIRECTORY` records source/dirty flag, compiler, binary/corpus/log hashes, exact argv, seed, budgets, runtime status and failures. Exit0 only when all3 actual target runs complete; missing tools is NOT_RUN/nonzero and any failure/timeout/incomplete runner is FAIL. CI short and scheduled modes retain artifact files. Seed bytes are labeled synthetic CC0-generated. No user photographs or secrets are checked in.

Android FuzzBridgeContractTest exercises actual JNI size checks, nonfinite inputs and cancellation/finish/stale-handle races. Compiling it does not count as executing JNI. Device result remains NOT_RUN until the explicit serial-aware instrumentation command completes. Runtime source fixes belong003/031-060/068; report minimal reproductions rather than changing those sources.
