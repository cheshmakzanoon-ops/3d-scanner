# C15 studio interaction

All three existing viewers now provide buttons for every essential orbit/pan/zoom action, fit/reset and top orientation, plus custom semantic actions and localized camera state. Camera state is a saved `StudioPose` (degrees, bounded zoom, normalized pan), separate from immutable model data. Touch gestures update this same state; button commands never restart reconstruction. Point semantics derive sparse/dense representation from the actual JSON field. The diagnostic mesh viewer explicitly discloses face sampling on large meshes; exported geometry is unchanged.

`PhotographicModelViewer(file, features=StudioFeatureActions(), surfaceFactory=null, onClose)` retains trailing-lambda call compatibility. The factory type is `(Context, LoadedPhotographicModel, (String)->Unit)->StudioRenderSurface`; the default is the verified GLES path. The owner068 cancellable loader owns validated CPU data and read-only original GLB bytes. Surface pause/resume/close is bound to the lifecycle owner; CPU references are released when the load leaves composition. Optional alternative renderer factories receive that already validated load rather than reopening a mutable file.

`StudioFeatureActions` exposes nullable real edit/measure/LOD/export actions. Missing providers produce no selectable button; this does not imply the underlying services are complete. `StudioEditingPanel(EditController,onRecipeChanged)` bridges the real066 controller: orientation, conservative crop, known-distance reference and undo/redo. Source-frame coordinate entry is explicit. Metric scale requires two distinct finite coordinates, an actual positive known distance, uncertainty and reference label; no inferred meters. Persistence/materialization remains with005/009/003/067.

Final manual accessibility/device/resource gates remain required.

An alternative-backend failure now closes the old renderer and mounts a keyed replacement AndroidView containing GLES, preserving the same saved camera pose. `RendererFallbackTest` causes an asynchronous test-only backend failure after attachment and requires the actual replacement PhotoGlView to submit frames; a merely created but unattached fallback fails this regression. Alternative surfaces also receive the common pointer-gesture path, so the drag/pinch instructions remain truthful across backends. Default GLES retains its native touch handler and receives atomic pose updates, avoiding duplicate gesture handling.
