# Agent 038 — calibrated camera resection

The existing `registerCamera(span<Observation>, threshold, seed)` and five-double C row layout remain unchanged. World coordinates share the anchor's arbitrary scale, images are calibrated normalized x-right/y-down rays, and rotations are proper row-major world-to-camera SO(3). Exact/near-planar samples use a calibrated metric plane-homography decomposition with two-sign cheirality selection; nonplanar samples retain normalized DLT. Collinear or insufficient-support cases remain explicit failures. Robust refinement accepts only decreasing Huber objective steps. Consensus identities are unique original row indices.

`rf_register_camera_json` is now explicitly noexcept; the complete boundary, including error-message construction and allocation, catches all exceptions and returns null on allocation failure. Successful strings remain malloc-owned and released with `rf_free`. Callers must handle null separately from JSON errors. Existing scoped cancellation is checked every RANSAC iteration and every refinement step; cancellation cannot be swallowed by a robust sample rejection.

The focused C++ regression is executed by `tests/test_agent_038_native.py` against the actual built library, including multi-axis camera rotations, tilted planar and near-planar surfaces, noise/outliers, three world scales, allocation-failure injection and live scoped cancellation. It is not a physical-scene or Android runtime qualification.
