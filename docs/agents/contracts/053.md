# 053 observed fusion orchestration

Fusion validates supported dimensions, exact depth/confidence buffers, proper
camera poses, sample count/provenance and source-pixel camera-z consistency before
spatial allocations. checkedVoxel uses long-double division with an int64 neighbor
margin; no floating-to-integer conversion occurs out of range. World coordinate
magnitude is capped at the same1e6 supported range as exporters.

Stable world/pixel ordering removes input-sample insertion bias. Only supported
local normals agreeing within30degrees and a continuous source visibility test
can authorize proximity fusion; unknown/mixed neighborhoods stay separate and
opposing thin surfaces are not merged merely because they are close. Weights
retain actual confidence/support, not a guessed physical accuracy percentage.
SurfaceMesh.observations keeps source sample ID, camera/pixel and compact vertex
mapping. Unused observations drop only when their vertex belongs to no output
triangle. Openings and isolated supported components are not filled or culled.

055 diagnoses actual face topology;056 independently proves only exact duplicate
or zero-area deletions. No vertex displacement, hole fill or generated face is
introduced. The final mesh reports boundary/component/nonmanifold/intersection
counts and explicit incomplete intersection diagnosis when its budget is reached.
Weighted normals are normalized independently of confidence magnitude before
angular comparison; finite positive scales preserve direction, while zero,
nonfinite and opposite directions reject. The054 depth adapter retains all nine
validated world-space neighbors, including slanted complete neighborhoods.
Fusion version3 is emitted;002/009 must use SURFACE policy
`observed-open-mesh-v3-normal-direction`, invalidating affected SURFACE/TEXTURE
identities while retaining unchanged DENSE identity and all geometry gates.

C ABI rf_surface_json is noexcept across allocation/error serialization, with a
constant error malloc fallback (nullptr on allocation exhaustion). Caller frees
all nonnull responses through rf_free. Cancellation escapes quality-warning catch
and becomes an ABI error. Standalone GLB/PLY files are staged beside destination
and renamed only after flush/close and a final cancellation checkpoint; operation
metadata publication across multiple exports remains002/023 responsibility.
