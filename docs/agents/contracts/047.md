# Agent 047: Bounded inverse-camera-z refinement and sparse-prior intervals

local(leftDepth,initialDepth,rightDepth,iterations,evaluate) returns depth/cost/uncertainty/evaluations; interval includes every visible conditioned sparse layer; propagate never crosses missing/depth-jump cells.

The kernels are inline so existing native targets can consume their headers without changing build ownership. The reserved .cpp is a translation-unit entry for build owner004. All camera-z values use arbitrary SfM units, never asserted meters. Test fixtures are analytic/synthetic. The CPU orchestration owner046 must wire and verify actual image reconstruction before final DONE.

SETTINGS_VERSION2 adds PlaneHypothesis{cameraNormal,observed} and PlaneHypotheses{values[6],count}.
planeHypotheses(calibratedCoarse,map,x,y,stride,origin,maxRelativeSpread=.055) fits inverse
camera-z over the nearest existing3x3 sampled-grid neighborhood. All nine depth/confidence
values must be finite, positive and observed; confidence must be<=1. Relative depth spread
must satisfy the caller bound, with relative inverse-depth plane residual<=.005. Missing,
border, depth-layer, grazing or ill-conditioned neighborhoods return one frontoparallel
proposal with observed=false. No missing depth is interpolated or published by this routine.

At most six proposals are returned: frontoparallel, the fitted camera normal, and four
fixed camera-X/Y perturbations of .035 before normalization. observed=true identifies an
observed-neighborhood seed; perturbed proposals are NOT measured normals or accepted surface
evidence. Caller046 must evaluate actual048 warped patch costs and retain the existing
frontoparallel baseline whenever no proposal improves it. The module does not create an
accepted depth, normal, confidence or visibility value. Candidate generation is constant
work/stack space and preserves arbitrary SfM depth scale.

planeDepth(hypothesis,calibratedView,centerX,centerY,centerZ,sampleX,sampleY) intersects a
camera ray with the proposed plane through the measured center. It returns0 on invalid,
nonunit, backward/grazing (view-ray cosine<.15), behind-camera, out-of-image or nonfinite
geometry, or a sample/center depth ratio outside[.5,2]. Caller treats0 as invalid cost,
never as a depth sample. Pyramid cameras must use the031 pixel-center intrinsics transform;
image resizing leaves camera-coordinate normals in the same camera frame. Every new setting
and SETTINGS_VERSION2 must participate in046/050 identities. Modified-quality mode remains
opt-in pending scene/resource qualification.

Independent tests cover asymmetric tilted-plane intersections on stride1/3 grids, curved
local tangents, depth layers, missing diagonal/invalid confidence, borders, unsafe planes,
depth ratio limits and scale1e-20..1e20. Run tests/test_agent_047_native.py or compile the
owned C++ test with warnings-as-errors and address/undefined/float-cast-overflow sanitizers.
