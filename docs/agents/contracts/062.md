# Agent 062 serializer contract

The C10 dependency is Agent 061 at `47e0fb4` (exact final integration SHA must be frozen by Agent 100). Geometry is borrowed through immutable spans for the duration of each call; no source geometry is mutated or copied. The proper `(x,-y,-z)` rotation agrees with C10/GLB and preserves triangle winding. Callers own private staging output and must discard it on any exception. A successful serializer return follows validation, byte-budget admission, cancellation checks and checked flushing; it is not external-provider publication. Agent 026 owns provider transport, and Agent 067 must keep requests bound to immutable artifact/revision identity.

`describeObj` returns exact byte counts and safe sibling OBJ/MTL/PNG names; `writeObj` accepts three distinct streams for photographic assets, one for point/surface assets. OBJ UV `v` is `1-canonicalV`, so a PNG remains unchanged and appears correctly in bottom-left OBJ consumers. Sparse/dense point output uses explicit `p` records, never faces. Surface output preserves indices, holes and components. Names must match `[A-Za-z0-9_-]{1,80}` and exclude case-insensitive DOS device names (CON/PRN/AUX/NUL/COM1–9/LPT1–9). OBJ lacks portable confidence/support/color slots: omission is disclosed in the descriptor and metadata; choose PLY for these fields. Source identity metadata is losslessly UTF8-hex encoded to prevent record injection. Asset/geometry validation and exact streaming preflight occur before the first output byte.
