# Bounded derived image levels v2

Reviewed supplying coordinate commit031 5c47000340f8b7fa6c3fa61841e9d6c7f2005103. PyramidLevel carries immutable SHA256 identity, exact originalToLevel PixelTransform, finite width/height, owned integer ARGB and 0/1 validity. Copy-out API and close prevent cached native-pointer lifetimes. Identity includes original content SHA256, complete caller-provided calibration/settings identity, full affine transform coefficients, dimensions and031 coordinate version. A settings identity MUST include calibrated/estimated provenance and lens coefficients. Cache schema2 is independent of original/capture storage.

PyramidRectifier.tiles consumes one caller-owned raw image, its exact rawToUpright EXIF map, a calibrated upright source lens and an undistorted target-level lens. At integer target centres it projects normalized target rays through source Brown distortion and inverse EXIF map, samples bilinear RGB, marks source's final row/column and outside borders invalid, and checks cancellation every row/before publication. Consumer owns each emitted tile and must release it before requesting the next. tileRows1..256; level<=4.5M pixels; no collection-sized decoded storage. Original loader owner012 remains responsible for raw decode budgets and release. 002 removes embedded loops only after identical fixture comparisons.

PyramidStore is only for a dedicated derived-cache directory. Checksum validates the entire versioned payload and exact dimensions/transform before accepting; atomic temp-file+fsync+rename publishes complete cache only. Byte eviction touches only matching SHA256.rfp files. Unsupported data, corruption and IO failures are cache misses/recomputation; originals/models are never candidates. Parent-directory power-loss durability and OS resource measurements remain separate qualification gates.

Production002 depth/photographic producer API: `PyramidRectifier.writeUprightRgba(sourceArgb,width,height,lens,targetPackedRgba,offset,originalSha256,calibrationProvenance,originalToLevel,storeOrNull,cancelled)`. Input pixels must be already EXIF upright and resized by012 loader; this adapter applies no second orientation. Build originalToLevel from031 `exif(rawWidth,rawHeight,orientation).then(resize(uprightWidth,uprightHeight,width,height))`. It rectifies into the existing packed depth/photo target, uses exact nine lens coefficients plus border/alpha/coordinate versions/provenance in cache identity, and optionally stores/reuses completed levels. Pass null store when030 has not admitted additional full-level cache buffers; this uses bounded tiles only. Return identity/hit/stored are cache diagnostics, not reconstruction success. Caller must discard the stage on cancellation and release each source bitmap before decoding the next.

Opaque source policy: all four bilinear-footprint neighbours must have alpha255. Transparent and partially alpha source holes remain RGB0/alpha0/validity0; no renormalizing through missing data. PyramidLevel rejects valid-mask texels whose stored ARGB is nonopaque. Tile is immutable with defensive copy-out arrays. Tests include partial-alpha holes, tile-row permutation, cache/uncached exact masks, caller mutation and the actual upright RGBA producer path.

The same `writeUprightRgba` has a lazy first-argument overload `sourceArgb:()->IntArray`: pass a decoder closure that reads exactly one bitmap, extracts owned ARGB and recycles the bitmap in finally. Cache hit verifies identity/mask before invoking the closure, so repeat stages avoid decoding entirely. The producer test requires exactlyone decode across miss+hit and byte-identical masked outputs. Target dimensions/transform/lens must be fixed before calling; incompatible decoder output count rejects.
