# Accessibility contract and audit

Reusable Compose modifiers expose headings, localized state descriptions, measured
or indeterminate progress, custom actions, grouped switch semantics and 48dp touch
minimums. Stage announcement policy announces transitions, suppressing every-frame
progress noise. Feature owners must attach these or equivalent semantics to actual
controls; a helper alone does not close a screen defect.

For library/capture/review/processing/studio/export/preferences/onboarding record
TalkBack, keyboard, switch access, 200% text, RTL, touch targets, focus restoration,
gesture alternatives and destructive scope. `AccessibilityAuditContract.incomplete`
rejects missing, stale, duplicate and non-PASS records against exact APK SHA256.
Device identity and recording/report paths must be real; this model validates
completeness, not the authenticity of a claimed recording. Manual results remain
NOT_RUN until a real operator performs the following audit.

1. Start fresh with TalkBack, navigate using swipe/focus only, create/import/review,
   reconstruct, inspect each available representation, export and reopen.
2. Operate every essential action with keyboard and switch access. Orbit/zoom/fit
   must have named buttons or accessibility actions, not only pinch/drag.
3. At 200% font scale, small phone/landscape/tablet, ensure all primary/destructive
   controls remain visible or scrollable, labels wrap and fields retain context.
4. Force RTL/pseudo-locales, inspect logical traversal and number/unit order.
5. Open/close dialogs and external picker, rotate/background/reopen; verify focus
   returns to initiating action or current route heading, never unrelated project.
6. Pause/resume/error stages must announce changed state once; unknown totals/time
   remain indeterminate. Destructive confirmation names project/original scope.

Automated instrumentation exercises actual application accessibility nodes and
keyboard-backed click/set-text actions. It cannot substitute for a human TalkBack
or switch-access session, color perception or physical-device qualification.
