# Verified revisit constraint v1

`LoopProposal` contains immutable source/revisit photo IDs, identical established component identity, target camera index, current shared-frame pose and bounded established landmarks with stable track IDs, world XYZ, normalized revisit observations and independent support counts. `verifyLoopClosure` runs real calibrated robust PnP; same-component identity, >=16 independently supported tracks, >=65% consensus and a spatial image-extent gate are required. Duplicate track IDs, wrong photos/components, weak/false correspondences and cancellation reject without mutating geometry. Result carries the recovered world-to-camera pose, exact supporting stable IDs, median normalized error, inlier fraction and before/after correction magnitude. Scale stays arbitrary. Spatial extent/support thresholds are conservative admission gates, not a proof that a symmetric physical object is unique.

Kotlin `LoopClosure.candidates` only schedules already verified pair proposals.
