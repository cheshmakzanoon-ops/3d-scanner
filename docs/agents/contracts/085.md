Frozen protocol: benchmarks/quality_protocols/texture.json. `uv_metrics` checks
bounds, degenerate UVs, positive-area triangle chart overlaps, anisotropy, chart
connectivity, density, alpha-supported faces and discontinuities across matching
geometric edges with duplicate UV vertices. RGB errors are measured after sRGB
transfer decoding. Seven fixed face-interior probes measure support; they do
not prove every texel is supported. Independent atlas support masks catch opaque
unknown regions. No support denominator is derived from supported output.

`geometry_retention` matches candidate faces against the actual original input
mesh in the same declared frame, rounded to six decimals. It rejects substituted
or duplicated triangles and reports dropped originals. Input normalization must
not change geometry; edits/decimation need separately declared evaluation mapping,
not this exact-face texturing gate. Density uses texels per declared world unit;
arbitrary-scale outputs never acquire metric scale from density.

`render` independently projects vertices with world-to-camera p=R*X+t and K,
right/down/forward camera coordinates, integer pixel centers and perspective-correct
UVs. GLB stored world coordinates remain right/up/back; calibrated R/t must map
that declared frame into the camera frame. This is a limited pinhole comparison,
not a production renderer. Near-plane crossing faces are unsupported and reduce
support; lenses must be independently rectified. No fitted image warp. A fixed
reference visibility/occlusion mask is mandatory; missing candidate pixels lower
support even if retained color residual is small. Held-out photographs are checked
against corpus photo ID/hash and must have role held_out. They never enter native
reconstruction. Alpha must retain unknowns; OPAQUE material with transparent
texels fails. Missing texture and altered embedded PNG bytes fail explicitly.

Run `python -m tools.qa.texture_quality descriptor.json --output evidence.json`.
Descriptor `scenes` array cases contain id, kind, candidate (GLB), original_mesh
(OBJ/PLY/JSON/GLB), settings and engine_artifact (files hashed), candidate_source_sha,
optional expected_png, optional independent_atlas_support_mask and mandatory real
manifest (corpus v1 local path). Paths are relative to descriptor. `held_out` list
entries: photo_id, photo, independent_visible_mask (nonzero eligible), camera
object with K 3x3, R 3x3, t3. Every scene is retained including failures. Reports
bind source/artifact/settings/engine/data/protocol/camera/visibility/visual hashes.
Review PNG panels show reference, predicted and 4x absolute encoded RGB difference;
missing eligible pixels are magenta. Quantitative metrics use linear RGB.
`python -m tools.qa.texture_quality.fixture ROOT` creates deterministic synthetic
checker GLB/PNG. `python -m tools.qa.texture_quality.baseline --output-dir EVIDENCE
--native-library build/host/librealityforge.so` executes the unchanged Middlebury
gate then independently decodes its actual GLB/PNG and measures UV/support/seams.
Stereo has no independent held-out camera and records held_out NOT_RUN.

An existing Middlebury gate PASS is separate from independent_uv_gate FAIL.
New independent thresholds do not rewrite or weaken the historical gates.
The baseline CLI aggregate `status` and process exit code fail when either gate
fails (exit1), including a historical PASS with measured UV overlap. The receipt
preserves the historical result as `legacy_baseline_status` and
`legacy_exit_code`; `exit_code` records the aggregate CLI result. Both gates must
pass for aggregate PASS/exit0. Thresholds and the historical subprocess are unchanged.

`python -m tools.qa.texture_quality.compact --native-library CANDIDATE.so
--candidate-source-sha EXACT_PROVIDER_SHA --output-dir EVIDENCE` directly calls
057's actual rf_textured_surface_compact_json with licensed existing Middlebury
images and published calibration, never ground-truth disparity. It retains full
original GLB/PLY, photographic GLB/PNG and native diagnostics, independently checks
geometry retention and UV/support, and binds source/settings/protocol/engine/input
and output hashes. A baseline library missing the new ABI yields NOT_RUN/exit2.
This actual compact adapter is separate from the unchanged historical legacy gate.
Native errors fail. Numeric independent gate failures stay visible. Neither entry
point supplies an independent held-out physical camera.
