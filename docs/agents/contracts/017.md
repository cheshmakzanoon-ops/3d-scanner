# Agent 017 contract — measured overlap and capture diversity guidance

## Scope

This contract supplies bounded, session-safe guidance from **observed image overlap and
validated local geometry**. It does not estimate the fraction of the whole object that has
been captured. Unknown and unobserved surfaces remain unknown.

Production types live in
`app/src/main/java/com/realityforge/scanner/capture/guidance/`.

## Session and lifetime invariants

- Every frame, quality signal, motion signal and geometry result carries an immutable
  `CaptureSessionIdentity(projectId, revision, sessionToken)`.
- Starting another session clears all retained summaries. A callback from an earlier session
  returns `STALE_SESSION` and cannot update visible advice.
- Candidate frame sequence numbers strictly advance. Delayed or replayed geometry evidence
  returns `OUT_OF_ORDER_EVIDENCE` rather than rewinding advice.
- `CaptureGuidanceEngine` public access is synchronized. The injected matcher executes outside
  the engine lock; a session change while matching is therefore rejected when its result arrives.
- Only bounded summary objects are retained. Image buffers, descriptors and matcher-owned
  payloads remain caller-owned and are never retained by `CaptureGuidanceCoordinator`.

## Evidence contract

`PairwiseGuidanceEvidence` uses these units and meanings:

| Field | Meaning |
|---|---|
| `rawMatchCount` | Candidate descriptor matches before reciprocal/geometric filtering |
| `reciprocalMatchCount` | Mutually consistent descriptor matches |
| `geometricInlierCount` | Matches accepted by the stated geometric model |
| `occupiedImageCells / totalImageCells` | Image-grid support for geometric inliers; **not object coverage** |
| `medianImageDisplacementFraction` | Median pixel displacement divided by the larger image dimension |
| `poseRotationDegrees` | Relative camera rotation in degrees |
| `translationOverSceneDepth` | Relative translation norm divided by a robust positive scene-depth estimate |
| `medianParallaxDegrees` | Median triangulation parallax in degrees |
| `normalizedReprojectionError` | Median reprojection residual in normalized camera coordinates |
| `dynamicOutlierFraction` | Fraction of tracked support rejected as inconsistent with the rigid scene |

Counts are internally consistent, optional metrics are finite and range-checked, and a
validated pose must use `ESSENTIAL_POSE`. Reference and candidate must be distinct frames in
the same session, with the candidate following the reference.

`PipelineGuidanceMatcher` is the production seam for Agent 002. It accepts only lightweight
photo/feature/calibration artifact references and maps an owner-supplied
`PipelinePairEvidence` into the guidance contract. `REPLAY_FIXTURE` provenance is reserved for
tests and benchmark replay; production pipeline evidence is marked `ENGINE_MATCHER`.

## Timestamp association

Quality and motion inputs must use the same monotonic clock as frame identities (Android
`SystemClock.elapsedRealtimeNanos()` at integration). A signal affects classification only when
its session matches and its timestamp is within `signalAssociationToleranceNanos` of the
candidate frame. A temporally distant high-confidence risk may be disclosed as stale context,
but its evidence ID is not included among the evidence used for the current classification.
Distant acceptable/stable signals do not create risk reasons.

## Output semantics

`GuidanceObservation` publishes stable enum codes for UI/localization:

- outcomes: `UNKNOWN`, `INSUFFICIENT_OVERLAP`, `REPEATED_VIEW`, `PURE_ROTATION`,
  `MOVING_OBJECT`, `QUALITY_LIMITED`, `USEFUL_DIVERSITY`;
- action codes: wait for evidence, add overlap, hold steady/retake, keep the object still,
  move sideways, change viewpoint, or capture this view;
- image overlap is separate from geometric confidence;
- `objectCoverage` is always `UNKNOWN_NOT_MEASURED` in this live pair-evidence module;
- evidence IDs and reason codes are deterministic and suitable for diagnostics/localized copy.

No UI should convert retained-photo count, match count, elapsed time or advice history into a
monotonic “object coverage” ring.

## Default resource policy

The version-1 policy retains at most 12 geometry summaries, 12 quality summaries and 12 motion
summaries, prunes evidence older than 20 seconds, publishes no faster than every 250 ms and
associates quality/motion within 180 ms. Limits are constructor-validated and can be supplied by
Agent 030 after device measurements. The module reports retained counts and a conservative
summary-size estimate; this is not a substitute for physical process-memory profiling.

## Required owner integrations

- **002:** provide real matcher/pose evidence from immutable feature and calibration artifacts.
- **010:** map stable reason/rejection codes into shared diagnostics without changing semantics.
- **013:** provide stable photo/lens/calibration identities and monotonic capture timestamps.
- **014:** own CameraScreen/session wiring and render `GuidanceObservation` only for its session.
- **016:** adapt timestamped live quality observations; do not pass frame buffers.
- **030:** replace default cadence/window values only from measured resource budgets.
- **075:** own localized explanatory copy for the stable action/reason codes.

## Physical comparison protocol (still required)

Use authorized, same-device, same-lens captures of the same rigid objects under controlled
conditions. Freeze the object set, route, light, photo budget and reconstruction settings first.
Collect paired guided and unguided sequences without discarding failures. Report per sequence:
photo count, registered cameras/fraction, independently defined observable-surface completeness,
reconstruction rejection/failure, elapsed capture time and device identity. Synthetic/replay
fixtures validate state rules only and must never be labeled physical evidence.
