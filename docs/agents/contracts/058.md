# Agent 058: Compact UV charts and atlas packing

UVAtlasLayout via layoutSurfaceCharts(mesh, UVAtlasSettings) returns bounded adjacent surface charts with exact source-face provenance, source-local coordinates and upper-left UVs. Shelf packing deterministically lowers declared uniform density to a fit; it never silently loses faces.

Consume UVAtlasLayout.charts, use chart.local for raster barycentrics and chart.uv for glTF coordinates. edge accepts 2048/4096; padding 2..16. Report actual texelsPerUnit, maximumStretch and utilization. Default projection requires coplanarity; optional bounded curvature has an explicit stretch admission.

Coordinates remain internal x-right/y-down/z-forward, arbitrary world units. New helpers are inline to preserve existing CMake builds; the reserved source translation unit includes the same header for owner004 registration. No runtime downloads or new dependency are introduced.

UVAtlasLayout.groups owns each packed rectangle and its source-face membership. UVAtlasLayout.charts[sourceFace] remains the exact per-face barycentric mapping, with shared chartId/rectangle/common tangent basis. Grow only across edges with exactly two incident faces and consistent winding. Each added triangle must have no positive-area 2D overlap with any member. At most 64 faces form a chart by default (hard 256); sharp/nonmanifold boundaries retain separate charts. A boundary-edge basis reduces diagonal bounding-box waste. Pack one gutter per group, not per triangle. The baker must raster a group once, resolve actual triangle ownership at each texel, preserve unsupported interior alpha and fill only exterior gutters. Production 057 uses a linear sampler without mipmaps; a finite gutter does not qualify arbitrary mip levels.
