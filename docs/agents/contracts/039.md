# Agent 039 — bounded restartable registration

`IncrementalRegistration.grow` preserves existing call sites with additive options: unique immutable source photoIds, an input-identity/checksum-validated RegistrationFrontier, checkpoint callback, verified-neighbor candidate lookup and an explicit total pair-evaluation budget. The source identity includes ordered-by-ID dimensions, focal projection and feature coordinates; stale input and duplicate identities fail before matching. Anchors must remain identical when resuming.

Native calls retain <=12-camera windows (the two anchors plus newest ten frontier cameras), common arbitrary-scale world poses and complete <=100000-observation tracks. Reciprocal matches are cached in a512-pair LRU, with at most4000 one-to-one identities each. Pending candidates are ranked by actual unambiguous two-view-supported landmarks; only eight candidate row buffers (each <=5000 rows) are retained. Verified-neighbor callbacks prevent quadratic pair scheduling for large overlap graphs; absent callbacks use the bounded exact-reference path and enforce a declared evaluation budget rather than silently truncating photos.

RegistrationFrontier schema2 preserves source photo/camera mappings, proper finite SO(3) poses, input identity and explicit latest failure reasons. The frontier also embeds036’s checksummed source-observation snapshot; all its source photos must be among persisted registered cameras. Whole-payload SHA256 and strict exact-length readers reject corrupted/unknown/oversized/stale data. Checkpoints are intermediate state, never a completed project or cache-publication claim. The coordinator owns durable stage identity, atomic writes and final publication.

Test-only analytic geometry doubles exercise 30/80/250-photo chain scheduling, bounded native camera windows and interrupted/resumed growth; these tests do not qualify real-world geometry or replace production-JNI instrumentation. Baseline JNI independently verifies native inlier identities and positive-depth reprojection before accepting a camera.
