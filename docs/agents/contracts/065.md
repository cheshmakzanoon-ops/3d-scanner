# C10 derived LOD contract

`simplifySurface(SurfaceAsset, LodRecipe, optional UV span, Cancel)` returns an owned
`LodGeometry` and measured `LodReport`. Its `surface()` spans expire with the owner.
The source is immutable. The dependency is Agent 061's canonical asset contract,
implementation commit `47e0fb4`; consumers must integrate it first.

Version `rf-constrained-endpoint-lod-v2` collapses manifold interior edges to an
existing endpoint only. All boundary vertices and coincident vertex identities
(chart/material/sharp-normal seams) remain fixed. The manifold link condition,
duplicate-face rejection and positive face-normal cosine test prevent a collapse
from joining components, closing holes, folding faces or erasing thin features
outside the explicitly chosen displacement budget. Targets that cannot be met
within these constraints are refused without returning a partial result. Odd
face-count targets can be unreachable because a manifold interior collapse
removes two faces. Identity reduction returns actual geometry, not a triangle
skip in the renderer.

`maximumDisplacement` bounds every original vertex's displacement to its surviving
endpoint. `maximumUvDisplacement` bounds the corresponding normalized-atlas
coordinate displacement. They are conservative correspondence bounds, not a
claim of independently measured full-surface Hausdorff or perceptual texture
error. Closed/open/disconnected synthetic cases exercise the implementation;
Agent 084/085 still independently qualify eligible real assets. A zero UV budget
refuses any change of UV correspondence; the default never silently rebakes.
There is no automatic hole filling, material blending or inference of surfaces.

Result provenance keeps the parent asset and original source SHA-256, sets the
algorithm version, and clears `assetId`. Owner 009 must assign the derived stage
identity from the parent, complete numeric recipe, UV/normal/material inputs and
engine version before persistence/publication or reuse. The LOD itself is not a
completed project result. Full atlases remain in the parent; surviving UVs retain
references to those same photographed pixels.

Work is bounded by caller vertex/triangle limits and `maximumWork`; cancellation
is checked while scanning candidates/faces and before return. Exhaustion,
nonmanifold/degenerate input, invalid attributes and unsupported reductions throw
`rf::Error` and leave the master untouched. `LodReport` reports input/output counts,
actual collapses, locked vertices, work and displacement; callers must not convert
it into an object completeness or quality score.

The focused Python driver also consumes the actual published owner 055 topology
implementation when available. Set `RF_TOPOLOGY_CONTRACT_ROOT` to its exact-commit
checkout (or use the final integrated tree); the same fixture execution then
checks independent component/boundary counts, winding, degeneracy, nonmanifold
vertices/edges and intersections. The validated handoff used owner 055 commit
`47705706512d04da64fd5c090b2325d91d888aa1`. Independent GLB decoding verifies
face count/bounds and the expected -Z winding after glTF coordinate conversion.
The C10 source now uses platform zlib for PNG validation; standalone drivers link
`-lz`, matching owner 004's existing `ZLIB::ZLIB` build contract.

Version 2 batches disjoint endpoint stars and updates only affected faces, rather
than rescanning the entire mesh for every edge. A 20,000-triangle synthetic grid
reduces to 10,000 triangles within a predeclared 2,000,000-work-unit budget and
maximum displacement 3. These units count bounded algorithm work, not measured
phone milliseconds/RAM. Nonmanifold vertex links (including pinched/bow-tie fans)
are rejected before reduction. Cancellation also checks preprocessing, sorting
and each accepted/rejected candidate. The changed deterministic collapse order
has a new algorithm version so a previous variant cannot be silently reused.

`parentVertexIndices` maps each surviving endpoint to its exact vertex ordinal
in the immutable input C10 view. `parentTriangleIndices` maps each surviving
rewritten face to its original parent face ordinal. Keep these sidecars with the
derived artifact and compose any canonical-to-legacy SurfaceMesh/TextureVertex
mapping in the source owner adapter; the parent's per-observation provenance is
never silently reassigned to an unrelated vertex. Removed samples remain in the
unchanged master. Incoming owner 053's b780ab9bd086cb9d05f2ae123fc84427326315d8
request is consumed; incoming owner 055's 2c659b78b597f63988cb65e9cce9d44fc475bac3
request is exercised through the real independent topology fixture checks.
