# Intrinsic model v1

`rf::IntrinsicModel` carries immutable lens/crop identity and pixel dimensions with `[fx,fy,cx,cy,k1,k2,p1,p2,k3]` and fixed/refinable flags. Integer pixel centres; x right/y down/z forward. Projection returns 2x9 intrinsic and 2x2 ray Jacobians. Newton unprojection rejects singular/folded local mappings and nonconvergence. The solver must admit only observable groups; insufficient view count, radial extent or depth diversity cannot move calibration. `applyIntrinsicStep` preserves fixed values and clips refinable values to physical bounds and 3-sigma priors. These checks are conservative admission criteria, not a proof of complete statistical observability. Measured profiles remain fixed by default. No world-unit claim.

041 consumes these functions in its optimizer; 009 must include full parameter/provenance/version identity and 003 must pass fixed/refinable metadata explicitly. The source is compiled directly until 004 registers it.
