# Agent 060: Measured exposure and color consistency

ExposureBalance retains legacy gains API, adds cameraSupported/confidence, rejected sample/pair counts and independently withheld residuals. Each fifth sample is withheld. Improvements must pass train/all and heldout median gates; unsupported views remain identity. Transfer functions explicitly reject nonfinite values. Cancellation checked every128 inputs and pair/channel.

Existing balanceExposure API remains; expose heldout metrics and support provenance in photographic diagnostics. No spatial radiometric terms without authorized varying-light photographic evidence. Existing texture path consumes corrections automatically.

Coordinates remain internal x-right/y-down/z-forward, arbitrary world units. New helpers are inline to preserve existing CMake builds; the reserved source translation unit includes the same header for owner004 registration. No runtime downloads or new dependency are introduced.

Per-channel held-out gate: a median across RGB must never hide a red/green/blue regression. Each channel now requires independent held-out improvement; an unsupported channel stays at identity even when the other two improve. A single-channel exposure improvement is retained when the aggregate RGB median is unchanged at zero. channelCorrectionAccepted and per-channel held-out errors expose this decision. The adversarial fixture deliberately makes withheld red samples contradict the training red gain while green/blue remain valid; a separate pure-red fixture prevents global-median suppression of useful corrections.
