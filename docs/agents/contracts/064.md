# Agent 064 serializer contract

The C10 dependency is Agent 061 at `47e0fb4` (exact final integration SHA must be frozen by Agent 100). Geometry is borrowed through immutable spans for the duration of each call; no source geometry is mutated or copied. The proper `(x,-y,-z)` rotation agrees with C10/GLB and preserves triangle winding. Callers own private staging output and must discard it on any exception. A successful serializer return follows validation, byte-budget admission, cancellation checks and checked flushing; it is not external-provider publication. Agent 026 owns provider transport, and Agent 067 must keep requests bound to immutable artifact/revision identity.

`describePly` reports exact total bytes, vertex stride and optional attributes. `writePly` supports binary little-endian (default) and ASCII. Stable property order/types are double xyz, optional double normals, uchar RGB, float confidence, uint supporting_views, then triangle face list uchar/uint vertex_indices. Sparse and dense labels differ. A photographic source surface exports as observed_surface with an explicit texture-omitted comment, never photographic appearance. Unknown units remain arbitrary in metadata. All fields, counts, faces and output budgets are validated before emission. Generic readers need not understand custom evidence comments/properties.
