# Offline capture guide contract v1

`OnboardingScreen(onComplete,onSkip,modifier)` is skippable/revisitable and saves the current page. Back moves within the guide or skips at its start.071 owns navigation;079 owns completion-version persistence. `CaptureHelp` exposes contextual overlap guidance.

`CaptureGuide.VERSION=1` and stable step IDs cover subject, overlap, optics, review, calibration, limitations and privacy. The included offline `onboarding/checkerboard-9x6.svg` is byte-identical to the approved board:10×7 squares/9×6 inner corners. The canvas preview uses the same alternating geometry. A board or lens calibration never promises measured object scale.

Copy matches the currently compiled baseline: at most12 sparse photographs and8 depth views, open/partial observed output, arbitrary scale unless independently referenced, and no app networking. There is no fake completeness score, network-dependent tutorial or asset download. Provider exports may have their own cloud behavior, and uninstall removes private originals.

Content geometry/external-reference tests and guide state tests are executable. Real fresh-install capture/import, TalkBack, large-font and offline usability remain separate device/manual evidence.
