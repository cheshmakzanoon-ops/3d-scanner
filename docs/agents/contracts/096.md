and honest `capture_audit_not_reconstruction` output. Hostile archives fail via
`ValueError` before unrestricted allocation/decode. Supported image subset is
JPEG/PNG with documented original/decode budgets. Not an Android parser replacement.

`tools/security/scan.py ROOT --scanner-python PYTHON --requirements FILE
--suppressions POLICY --source-sha FULL_CLEAN_SHA --output REPORT` returns schema1 status PASS/FAIL/NOT_RUN,
independent static/secrets/dependencies checks, redacted findings and all justified
suppressed records. Exit0/1/2 respectively. Selected tools must match exact pinned
versions. Source-hash-specific policy expires; stale findings do not disappear.
Root099 binds candidate source/artifact hashes around this raw tool receipt.


Integrated follow-up retains `raw_findings`, `suppressed`, `findings` and
`finding_counts` (raw/active/suppressed totals plus scanner/rule/severity counters).
Paths are canonical relative to ROOT. Reports bind Git source/dirty state, selected
source file byte fingerprint, policy hash and selected requirements hash. Exact
`--source-sha` requires a clean matching candidate, and source/input drift during
execution returns NOT_RUN. Omitting the dependency lock remains NOT_RUN.

The 2026-10 integrated review explicitly classifies generated public content
hashes, npm integrity fields, SDK archive names and desktop QA subprocess/XML

and expiry; conditional HTTPS fetch exceptions also bind origin-manifest bytes.
New credentials, changed files and dependency advisories stay active. No rule,
severity, raw finding or duplicate is hidden. See the threat model for scope.
