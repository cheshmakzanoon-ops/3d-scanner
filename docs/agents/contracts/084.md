# Independent geometry protocol v1

Frozen thresholds: benchmarks/quality_protocols/geometry.json. Evaluate only after
reconstruction. `similarity(source, target)` fits proper Sim(3) from declared
corresponding evaluation landmarks; `transform` applies row-vector x'=s*x*R+t.
Camera centers use that same gauge; world-to-camera rotation becomes Rcam*Ralign.
Do not optimize reconstruction against evaluation references. Input units remain
arbitrary unless corpus scale is independently verified. Reports normalize all
surface errors to the full reference bounding-box diagonal.

`evaluate(cv, cf, rv, rf, eligible_reference_points)` computes candidate area
samples to exact reference triangles and independently fixed eligible reference
samples to exact candidate triangles. Points stay labeled points. Visibility
must be established independently before candidate evaluation (reference ray
casting or operator-defined immutable reference-face mask); never derive the
eligible denominator from retained output. The evaluator hashes this sample file.
No estimate of unobserved physical surfaces follows from open-patch accuracy.
Topology includes boundaries, components, nonmanifold edges, winding, degenerate
and coordinate-duplicate faces; self/coplanar intersections execute up to frozen
5000-face budget. Larger assets explicitly return NOT_RUN_BUDGET and fail the
full gate. This budget is a harness limit, not evidence of no intersections.

Run `python -m tools.qa.geometry_quality scene.json --output receipt.json`.
Descriptor: `{"scenes":[{"id":"object", "kind":"synthetic|real",
"candidate":"output.ply", "reference":"independent.obj",
"eligible_reference_points":"fixed_xyz.json", "settings":"settings.json",
"engine_artifact":"librealityforge.so", "candidate_source_sha":"40 hex",
"manifest":"private/manifest.json", "cameras":{"imported_ids":["a","b"],
"registered_ids":["a","b"]}}]}`. Optional alignment_landmarks object contains
candidate/reference Nx3 arrays, independent correspondence ordering. Optional
camera estimated_centers/reference_centers and estimated_rotations/reference_rotations
match registered IDs. Normalized JSON has vertices Nx3 and integer faces Nx3.
Native ASCII PLY and triangular OBJ are supported. Unsupported formats fail.
Corpus manifest is mandatory for real scenes and uses Agent083's validator after
root integration; reference hash must equal corpus reference. Every case retains
PASS/FAIL, artifact/reference/eligibility/settings/engine/protocol/descriptor hashes
and candidate/tool source identities. Numerical PASS does not close missing
physical corpus/workload gates. Failed cases remain in reports; no favorable mean.

Current C10 single-mesh, untransformed, self-contained GLB2 is also supported;
right/up/back coordinates are preserved as stored (reference must declare the
same frame or use explicit posthoc gauge). Bounded accessor decoding respects
strides/offsets and rejects required extensions, external buffers, animation,
multiple meshes and transforms. Unsupported subsets fail rather than mismeasure.
`python -m tools.qa.geometry_quality.baseline --output-dir PRIVATE_EVIDENCE`
runs all four unchanged baseline gates with per-command exits and source/engine hashes.
