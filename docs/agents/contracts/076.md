# Adaptive design contract

`ui.designsystem.AppTheme(darkTheme = isSystemInDarkTheme())` supplies semantic Material3 typography and accessible light/dark colors. `ScreenFrame` bounds content to 1200dp, respects safe drawing insets and leaves scrolling to its caller. `EvidenceCard` labels neutral/partial/error evidence without an invented coverage score. `LabelledToggle` provides one labelled switch action and a 48dp target. `LayoutPolicy.columns(widthDp,fontScale)` reduces columns as font size grows. Use wrapping FlowRows and vertical scroll/list containers for feature actions; never constrain text to one fixed height.
