# C14 renderer contract

`RenderControls` provides degree-based orbit, normalized pan, magnification and reset. It never mutates the master asset. `StudioRenderSurface` owns an Android view plus its controls and explicit resume/pause/close lifecycle. `RenderBackend` adds surface attach/detach, resize, frame submission and resource admission statistics. Calls to Filament are confined to its creating main thread; GLES calls stay on GLSurfaceView's GL thread.

`FilamentBackend.create(RenderBudget)` initializes Filament 1.56.0 and gltfio. `load(localGlbBytes, InspectionMode)` runs the project's safe parser before native loading and rejects external resource references again before `loadResources`. Supported modes are faithful unlit photography and explicitly synthetic neutral illumination on observed geometry. Neutral illumination is an inspection aid, not measured PBR appearance. Wireframe and normal overlays remain the existing diagnostic-viewer responsibility until independently qualified.

GLB source geometry is transformed only for display with uniform bounding-sphere normalization. The supplied GLB's right-handed y-up coordinates and UVs are preserved. Photographic materials use `KHR_materials_unlit`; no extra image or model is downloaded. A mode-specific JSON material is constructed in a bounded in-memory copy; original file/arrays are never modified.

`RenderBudget` estimates file/geometry/image CPU copies and GPU buffers/mip storage before allocation. Estimates are not driver-residency measurements. Its defaults are admission ceilings (192 MiB CPU, 96 MiB GPU, 4096 texture edge), not a physical-device qualification result. Exceeding a budget refuses the asset; it does not silently lower reconstruction quality.

Detach destroys and flushes the swap chain before the caller releases its Surface. Close removes renderables, destroys gltfio resources/materials, camera/light entities, scene/view/renderer and finally the engine. Close is idempotent. `FilamentStudioView` stops frame callbacks on pause/detach/failure and reports fallback requests; failure never marks a scan result invalid or alters it.

The GLES path remains the default. Enabling Filament for a shipping hardware profile requires dependency registration, 16 KB checks, actual photographic pixel comparison, lifecycle stress, memory/upload/frame pacing measurement and the exact-device receipt. No optional renderer switch constitutes successful qualification.
