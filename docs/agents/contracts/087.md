# Resource evidence interface

`tools/device/resource_profiling/profile.py collect|analyze` emits version1 local JSON. Raw identity includes installed app SHA256, input/settings hashes, serial/fingerprint/ABI/emulator flag and operator conditions. Per-sample counters preserve unavailable values as null; validation rejects restarts, stale debug PIDs, gaps, impossible memory/battery/thermal data. Native/Java heap PSS is named separately from debug native/Java allocated bytes. Output PASS means trace integrity, never budget/energy/physical acceptance.

`ResourceProbe.reset(context)` then `ResourceProbe.record(context,stage)` are explicit debug-only hooks. At most2048 bounded stage events include PID, device monotonic nanos, actual Java/native allocation, totalPSS and thermal state. No telemetry/networking or product UI dependency.
