# Agent 032: Bounded feature extraction

FeatureExtractor(settings).extract(photoId,contentSha256,file,decoderIdentity,projection,cancelled) owns one bounded decoded Bitmap and temporary Mats, returns Closeable FeatureFrame with read-only metadata and borrowed descriptor access. Settings default3500 SIFT/1600edge preserve baseline. FeatureFrame.withDescriptors never transfers Mat ownership; caller closes each frame before admitting another collection image. Projection and decoder identity come from031/045; Core.VERSION and exact settings enter SHA256 identity.

All pixel/ray conventions follow031: x-right/y-down/z-forward, arbitrary world scale. This implementation does not itself admit larger reconstruction profiles or claim physical-device qualification. Combined coordinator wiring and actual runtime fixture evidence remain separately recorded gates.

SIFT can return additional equal-response keypoints at its nominal nfeatures cutoff. The v2 service explicitly retains the first maxFeatures rows in SIFT output order; ordinary baseline rows/descriptors are otherwise unchanged. This cap is identified by the v2 settings hash and measured separately from quality qualification.

Resource/cancellation probe: `agents.a032.FeatureMemoryDeviceTest` runs actual Android/OpenCV,
warmup then two bounded extraction iterations by default, a separate-thread cancellation request
inside an observed native interval, and a successful extraction afterwards. `extractObserved`
brackets the same real SIFT kernel as `extract`; it preserves existing extract argument and
trailing-lambda semantics. The native call is not interruptible; the reported latency ends after
return and resource cleanup. Sampling records `/proc/self/status` VmRSS and malloc-accounted native
heap, with explicit source hash, dimensions, counts, failures and 2ms sample cadence. These are
sampled peaks and single-image probe budgets, not a whole-scan physical-phone qualification.

Instrumentation args: `a032_iterations`1..20(default2), `a032_rss_delta_budget_bytes`(default96MiB),
optional authorized `a032_photo_path`, and `a032_source_sha` for candidate binding. The default
procedural photograph is marked synthetic. JSON evidence is printed and retained in the target
app's private cache, including failed runs. Physical capture, native-allocator, total scan RSS,
and collection-wide quality gates remain separate.
