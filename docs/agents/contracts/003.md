# Receiving003 C3 scoped native boundary

Legacy Kotlin/JNI method names and packed buffer layouts remain. New sparse
adapters append token: reconstructCancellable, registerCameraCancellable,
reconstructMultiviewCancellable and bundleAdjustCancellable. Every scoped call
acquires one exclusive busy lease from a nonrecycled positive token, holds the
051 flag/progress state through execution and checks cancellation before and after.
Domain C cancellation JSON is freed and promoted to Java CancellationException;
cancellation cannot be downgraded to a registration quality rejection.

finishReconstruction signals stop and erases the handle; active leases retain
flag/progress ownership until the call exits. A second call on a busy token is
IllegalStateException, stale/unknown tokens are IllegalArgumentException. At most
16 active calls and16 registered handles; finishing active calls cannot create
unbounded parallel execution. cancel/finish remain false for unknown handles.

pollNativeProgress(token) returns schema1 LongArray of exactly7 fields:
[schema,stage,reference,tile,completed,totalOrMinus1,sequence]. Stage ordinals are
0Sparse,1Bundle,2Depth,3Consistency,4Surface,5Texture,6Checkpoint. sequence0 means
no stage has begun. Counts must fit signed64bit; no whole-scan percentage is
inferred. Polling does not acquire a busy lease and has constant storage.

Every JNI export has an outer no-throw guard preserving already pending VM
exceptions. bad_alloc becomes OutOfMemoryError, invalid geometry/arrays/handles
IllegalArgumentException, cancellation CancellationException, other failures
IllegalStateException. UTF chars use RAII even when constructing std::string fails;
malloc C responses use rf_free RAII before NewStringUTF. Core C ABI exports must
also contain allocation/error-format exceptions; null means OOM and is safe for
rf_free/callers. Strings are bounded4096UTF16chars, geometry buffers are finite
and checked before native calls; quality images cap16Mi pixels.

Actual hostJVM/JNI tests execute malformed inputs, cancellation, progress schema,
busy exclusion and finish races; a focused native test injects allocation failure
inside string creation and verifies UTF release and preservation of VM failures.
This is host JNI evidence, not an installed/minified Android release claim.
