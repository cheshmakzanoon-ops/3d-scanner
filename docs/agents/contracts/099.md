# Candidate qualification contract v1

Authoritative executable schema: `schemas/release-evidence-v1.json`. Fixed gate
set/coverage/age policy: `tools/release/qualification/policy-v1.json`; candidate
`policy_sha256` freezes exact bytes. Run `python -m tools.release.qualification.aggregate
--candidate CANDIDATE.json --candidate-apk APK --source-root INTEGRATED_CHECKOUT
--records RECORD_DIRECTORY --evidence-root SHA256_BLOBS
--output DECISION.json`. Exit0 PASS,1 FAIL,2 NOT_RUN/BLOCKED_EXTERNAL. No publishing.

The CLI also checks actual clean Git HEAD and APK bytes against candidate identity.
Each record contains schema1, three-digit agent, gate, full40 source_sha,64 APK
artifact_sha256, run_id, recorded_at UTCZ, exact command string/argv, environment
kind/identity, dataset id/kind/hash, status/blockers, finite numeric metrics and
evidence_sha256. The CLI requires a real backing blob named by that hash. Optional
tool_source_sha distinguishes the independent measurement tool from the measured
candidate. Optional protocol_sha256 is mandatory for passing geometry/texture/
resources and must match the candidate's frozen protocol map.

Every PASS requires positive executed_tests and zero failed_tests/skipped_tests/
disabled_tests. Source/APK/run/time must match; records older than168hours or before
candidate freeze fail. Duplicate gate/scene/device records fail. Unsupported status,
unknown fields, missing backing bytes and nonfinite metrics fail. Nonpass requires
a concrete blocker. Missing required receipts stay NOT_RUN. A single failed scene
or device remains FAIL; there is no average or readiness percentage.

Candidate: schema1, source_sha, artifact_sha256, run_id, created_at UTCZ,
policy_sha256, protocols map and explicit scenes/devices arrays. At least two
different authorized physical scenes bind manifest/reference SHA256 and at least
one supported physical device binds stable device ID/build fingerprint. Every
per-scene/device combination must pass. Physical records require measured physical
ARM64, emulator=false and exact declared device/scene/reference identities.
Empty arrays retain all gates and return BLOCKED_EXTERNAL. They never waive gates.

Fixed18 gates and exact owner IDs are in policy-v1.json. Actual checks include
candidate wiring completeness, native sanitizers, complete installed instrumentation,
30/100/250 resource profiles, photographic geometry/appearance thresholds, all four
target-tool round-trips, static/secret/dependency execution, signing/R8/AAB, offline
radios, recovery and independent external beta. Numeric criteria are executable
in `check_acceptance`. Geometry .95 registration/.95 independent completeness/
.01 normalized p95 error; texture .95 original support/.95 held-out support/.05
held-out linear RMSE/.10 seam p95/no UV overlap or opaque unknown/anisotropy<=4
match084/085 frozen protocols. Resource budgets remain owner087's frozen protocol;
all three promised profile runs and zero budget violations are required.

`quality_adapter` converts full084/085 per-scene reports and requires original
execution time/command/environment. It cannot promote PASS_LIMITED_UV, synthetic
or unexecuted held-out/physical reports. `branches` indexes all100 remote role
slots, treating presence as PRESENT_UNVERIFIED rather than completion.

The installed `journey` runner executes099's real app import/calibration/GLES
inspection/export/reopen/original-preservation regression and produces partial
instrumentation evidence only. It explicitly cannot satisfy the complete physical
journey/capture/edit/recovery/offline/release gates. The Android test supports
authorized physical bundles and default synthetic assets, preserving that label.
